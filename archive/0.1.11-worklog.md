# 0.1.11 — closing-kind hysteresis and transport floor crossing resolution

## Scope

`archive/0.1.11-hysteresis-worklog.md` investigated closing-kind hysteresis (V1) on the 0.1.10
tree. V1 eliminated 100% of velocity-caused reclassifications and reduced R5 repeats, but caused
a 126.1 km crust ceiling breach on seed 12 at 100 kyr/frame due to neighbouring records swapping
order during transport.

This job isolates and fixes the transport crossing flaw in `COL.floor`, re-evaluates the candidate
across all 32 runs of seeds 1–16 at 50 and 100 kyr/frame (5000 frames each), and lands 0.1.11 M1.

## The Flaw in `COL.floor`

During `COL.transport`:
1. Columns move by `colU[i] * dt`. When two plates converge with a large relative speed (e.g.
   160 mm/yr head-on at 100 kyr/frame = 16 km relative advance) that exceeds their pre-transport gap
   (6.4 km), column `i` overtakes column `j = (i + 1) % n` by `16 - 6.4 = 9.6 km`.
2. In `COL.floor`, the forward distance `d = st.colX[j] - st.colX[i]` becomes negative (-9.6 km).
   Adding `wrap` makes `d = wrap - 9.6 km`.
3. The previous code did:
   ```javascript
   if (d > P.wrap * 0.5) d = P.wrap - d;
   ```
   This converted `wrap - 9.6 km` into `d = +9.6 km`, discarding the direction of the overlap.
4. Next, the floor check tested:
   ```javascript
   if (d >= min) continue;
   ```
   Because `min = P.crushFloor = 3.91 km`, the code evaluated `9.6 km >= 3.91 km` as true!
   `COL.floor` falsely concluded the columns were separated by plenty of room and applied zero
   correction.
5. In the subsequent sort, the records swapped order. In K4, volume conservation scaled column 17's
   stack by `oldW / colW = 2.70 / 0.32 ≈ 8.4×` (60 km to 506 km), which K5 collapsed to 126.1 km.

## The Fix

1. **Crossing detection and directional restitution (`js/columns.js`):**
   ```javascript
   crossed = d > P.wrap - 2 * P.w0;
   if (crossed) d = P.wrap - d;
   min = (this.floorClassValid ? this.floorClass[i] === 1 : this.isClosingCC(st, i, j)) ?
   	P.crushFloor : P.gFloor * P.w0;
   if (!crossed && d >= min) continue;
   any = true;
   a = 0.5 * (crossed ? min + d : min - d);
   if (a > this.corrL[p]) this.corrL[p] = a;
   if (a > this.corrR[q]) this.corrR[q] = a;
   ```
   - When columns have crossed, the required relative displacement to clear the floor is `min + d`
     (moving plate `p` left and plate `q` right by `a = 0.5 * (min + d)`), pushing them back across
     each other to achieve the required `+min` separation.
   - Bounding crossing detection to `d > P.wrap - 2 * P.w0` ensures that sparse fixtures (such as
     the 12-column `riftFixture` with empty gaps `> wrap * 0.5`) are not falsely treated as crossed.

2. **Closing-kind hysteresis landed (`js/columns.js`):**
   ```javascript
   COL.isClosingCC = function (st, i, j) {
   	if (this.floorClassValid) return this.floorClass[i] === 1;
   	if (st.colPlate[i] === st.colPlate[j] || st.colGhost[i] || st.colGhost[j]) return false;
   	var held = st.edge[i] === P.EDGE.collide && st.edgeRPlate[i] === st.colPlate[j];
   	if (!(st.colU[i] > st.colU[j] || held)) return false;
   	return st.hFel[i] >= P.hOceanic && st.hFel[j] >= P.hOceanic;
   };
   ```
