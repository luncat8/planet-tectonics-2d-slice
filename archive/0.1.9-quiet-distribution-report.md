# 0.1.9 deferred quiet-frame measurement — current-tree distribution

**Scope:** report-only follow-up to the deferred measurement in `0.1.9-plan.md` §6. The
question is whether the largest no-event change in drawn column thickness and width has a
stable background that can later support a gate. No threshold, parameter or kernel change is
selected here. This report supersedes earlier matrix results: those were produced by a matcher
that later proved capable of false correspondence across the circular seam.

## Method and correspondence diagnosis

Ran `node experiments/contact-audit.js 5000 <seed> <kyr>` in report mode for seeds 1–16 at
50 and 100 kyr/frame (32 worlds). Full console records are in
`experiments/logs/0.1.9-quiet-distribution-<seed>-<kyr>.txt`; summarize them with
`node experiments/quiet-distribution-table.js`.

The trace work found two distinct matcher defects. First, an unusable ghost/sliver/consumed
record could block a nearby valid predecessor; seed 11 / 100 kyr initially had 14 unmatched
observations. Advancing past unusable candidates removed those misses, but did not validate the
pairings. A later trace found the predecessor branch lacked the same 0.4-column distance bound
as the successor branch, and the old and current circular walks could start at different seams.
That admitted a false pair at frame 3624: old x 40,030.1 km was paired with current x
24,850.8 km, with drawn thickness 19.0 → 80.0 km. Adding the missing distance bound before
realigning the circular walks left 1,607 unmatched records; letting the pointer cross the old
sequence's end by itself still left 1,591 unmatched in the same world.

`experiments/contact-audit.js` now aligns the old cyclic walk to the first current record, walks
at most one complete old-record lap, skips ghosts/slivers/already-claimed records, checks both
adjacent candidates against the same 0.4-column distance bound, and claims each old record at
most once. The final focused trace is
`experiments/logs/0.1.9-quiet-match-trace-11-100-after-fix.txt`; its unmatched count is zero.
The 32-world matrix also has **zero unmatched observations**. The corrected matcher changes only
measurement correspondence: surface, R1 event-site, R2, topology and crust summary lines are
identical to the prior matrix for all 32 seed/rate pairs. The original four `--strict` contact
audits were rerun after the final matcher change and each passes all 13 checks:
`experiments/logs/0.1.9-quiet-strict-<seed>-<kyr>.txt`.

## Results

| rate | retained quiet drawn-thickness change, min–median–max | maximum row |
| --- | --- | --- |
| 50 kyr/frame | 3.0–9.6–14.5 km | seed 14 |
| 100 kyr/frame | 7.4–14.7–16.1 km | seed 16 |
| combined | 3.0–12.9–16.1 km | seed 16, 100 kyr/frame |

The 32-world run retained 2,883 re-partitioned observations and reported zero unmatched
observations. Width differences above 10% are still excluded before either `quietDw` or `quietDh`
is updated. The reported width range of 9.4–10.0% is therefore censored, as is the thickness
range: a nearby, one-to-one positional pairing does not by itself certify identity through a
large split/merge/re-partition. In the final seed 11 / 100 kyr trace, an omitted candidate has
width 34.2 → 73.2 km (114.9%) and thickness 73.9 → 34.6 km; it remains excluded rather than
being treated as an ordinary quiet-frame change.

Earlier matrix values (46.3–77.6 km thickness and 351,978 re-partitioned observations) are
superseded. Their apparent high thickness changes came from the faulty circular correspondence;
they must not be used as validation of this matcher or as a threshold basis.

## Decision and next work

**Do not gate quiet-frame width or drawn-thickness change from this report.** The correspondence
rewrite removes the discovered false pairings and unmatched observations, but records changing
width by more than 10% remain censored. Before proposing thresholds, establish which of those
candidates retain material identity through re-partition, then measure them with an explicit
identity-aware rule. No physics change is justified by these measurements.

This is a measurement artifact only: no engine parameter, physics rule, checkpoint or slice
format changed. It does not start 0.4.2 Phase C, which remains held.
