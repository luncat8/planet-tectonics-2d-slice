improvements made in this session. Verdict: **the swap is correct and covered**; three small
gaps were found around it and are fixed here. Nothing in the engine changed.

Extra checks done by reading, not by running:

- the nine `<script src>` tags are in bootstrap order (`params` … `ui`, `sim` last, because

- the shipped `aria-pressed` values in the markup equal the renderer's defaults
  (`js/pt/render.js`: markers/ruler/melt/crust/relief all `true`; quality index 0; preset

- no `js/*` or `js/pt/*` file refers to a page by name, so the swap needed no engine edit;
- `experiments/lib.js` and `experiments/smoke.js` were re-pointed to `columns.html`, which is
  the only page that loads `js/*` now — correct, and their comments say so.

## Gaps found (and fixed in this session)

1. **A viewer could no longer find either engine.** `index.html` had no route to
   `columns.html`, and `columns.html` none to `index.html`; the swap made both pages silent
   about each other. Fixed: one link at the end of each page's help line
   (`index.html`/`particles.html` → "column engine", `columns.html` → "particle engine"), with
   the same muted `#keys a` / `#help a` style as the surrounding text.
2. **The two entry pages disagreed about what they are.** `columns.html` says "column engine"
   in its title; `index.html` and `particles.html` still said "particles". Fixed:
   "particle engine" in both, so the mirror stays byte-identical (`cmp` still passes).
3. **`AGENTS.md`'s files section never named the three pages or the harnesses.** After the
   swap that section is the only map of the repository for an agent, and it did not mention
   which page owns which engine. Fixed with a short page map and the harness list.

Also refreshed the record: `experiments/logs/0.3.0-index-entry-ui.txt` (the 37-check run that
now includes the page-parity gate) and `experiments/logs/0.3.0-index-entry-smoke.txt` (the
64-check column page run). The `0.3.0-p2.3b-ui.txt` log stays as it is: it is the record of the
harness at that milestone, and it is honest about what it covered then.
