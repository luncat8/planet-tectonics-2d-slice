# 0.2.5 — report (pile before death write-back rule)

The write-back rule (pile before death) frees the batching region `Vbirth` ≥ 16, allowing the section-wide duty to reach the 0.2.1 target (57–69%) without flattening the arc cone below the watchable 10–30 px band. The item 0.2.4 §7 left open is closed here by removing K7 lava drain, letting effusive eruptions pile before death exactly as tephra does.

**Landed: lava piles before death.** Both tephra and lava are held in the eruptive box and written back to the section stack only upon vent death. This restores the cone height since lava is not constantly shaved by the stack rules before death.
