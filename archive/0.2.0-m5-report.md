# 0.2.0 M5 — report (acceptance and tuning)

0.2.0 M5 is landed and the 0.2.x series is accepted. Worklog:
`archive/0.2.0-m5-worklog.md`; plan archived as `archive/0.2.0-plan.md`.

**What M5 still owed when this pass started:** the tuning decision (the sweep table
predated the landed R2/R5 gates and `params.js` still held the old value), an instrument
for acceptance §2.2 / §2.6 / §2.7 (none existed), the worklog, and the plan archive.

**Landed**

1. **Contact tuning: `P.kBeltGradient` 8 → 12.** The sweep was re-run on the landed gate
   (nine candidates × four strict legs, `experiments/logs/0.2.0-m5-sweep-gate-table.txt`).
   Every candidate passes the strict legs, so the discriminator is the worst *single-frame*
   needle: 12 is the only rate inside the historical 1.5 on all four legs
   (1.31/1.40/1.28/1.25); 8 reads 2.03, the rest 1.61–2.11, and 16 also loses R1 on
   3000/1/50. The standing-needle clause is no longer load-bearing (longest standing run
   0 frames on every leg).
2. **`experiments/acceptance.js`** — the whole-series pass, one section per §2 claim,
   delegating to the owning harness where one exists and measuring §2.2/§2.6/§2.7 directly.
   **48 / 48**, log `0.2.0-m5-acceptance.txt`.
3. **Two engine reds found by sampling the K9 sweep every frame** (M4 sampled it every 100
   frames, the HUD at 2 Hz, so both hid): `sorted` went red on every frame that consumed a
   column (K4's compaction leaves source indices in `sortOrder`, not a permutation), and
   `gap` went red on the frame a collision ended (the floor-class snapshot was taken after
   the classifier, so the settled gap was judged against a floor nothing solved for).
   Fixed in `js/columns.js` / `js/sim.js`; both fixes are provably geometry-neutral — the
   `contact-audit 5000 5 100 --strict` output is byte-identical before and after apart from
   its timing line.
4. **Eruptive tuning measured, nothing moved.** New `experiments/vent-tune-sweep.js` sweeps
   the km³ → m² scale over two live legs. ×1 (committed) sits mid-range for vent births
   (12 / 37 per leg, 12–21% duty); ×8 births nothing on one leg. A design-scale 10–30 px
   edifice needs ~50–450 toy cells² (3e7–2.6e8 m²) while the whole section makes 2.9e6 m²
   of melt in 150 Myr — so that gap is a melt-production question (`kMelt`/`kPlumeMelt`,
   0.1.x/0.3.x), recorded as deferred rather than tuned around.
5. **`checkpoint.js` D2 was measuring the wrong world** (the previous check's deliberately
   shifted cut) with a 1e-3 bound on a 6e-2 quantity. It now re-lays the good cut, uses the
   metric's own measured spread (3e-2; 1.3e-3–7.8e-3 across nine constants) and adds the
   gate that can fail: every K9 invariant for 1000 frames after the import. 53 / 53.
