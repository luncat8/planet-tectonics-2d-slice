# 0.1.8 follow-up — frame-stable contact-floor classification

## Scope

Close the 500 Myr / 100 kyr-per-frame ordinary-floor false failure without changing K5
transport, the floor constants, or any acceptance threshold. The failure was a classification
change after the geometry solve: K5 could lower `hFel` below `hOceanic` without moving `colX`,
turning an unchanged closing C-C gap into an ordinary gap after the floor had already run.

## Change

`COL.freezeFloorClass` snapshots each neighbour pair's closing-C-C status immediately before
K5. `COL.floor` and `COL.isClosingCC` read that snapshot for the rest of the frame. The snapshot
is refreshed every frame after K4 has settled topology and before K5 redistributes crust; a
K4 event that changes topology refreshes it through `COL.finalFloor`. Sorting invalidates it,
and reset clears it.

The cache is scratch state, not geological memory: it is rebuilt before its frame-local use and
does not enter checkpoints or the deterministic state hash. No `colX`, stack, ledger, force,
transport, or threshold arithmetic changed.

`experiments/m2-check.js` retains the stage probe that records the pre-K5 gap, classification,
and felsic thickness through each K5 sub-operation. This prevents the original category change
from becoming a false-green end-state test.

## Measurement

`node experiments/m2-check.js` now passes **289/289** checks. In the formerly failing 500 Myr,
100 kyr/frame leg:

- ordinary minimum: `0.1200 w0` at every reported stage (K3, K4, event, final floor, K5), above
  the required `0.1188 w0`;
- closing-C-C minimum: `0.0503 w0`, above the required `0.0495 w0`;
- final ordinary / closing minima: `0.2014 / 0.1083 w0`;
- per-frame cost: 1.750 ms/frame in the measured run, below the 4 ms budget.

The four strict default-planet audits show that this focused correction closes the floor defect
but does not claim unrelated 0.1.8 acceptance:

| frames / seed / kyr | result | open gates |
| --- | --- | --- |
| 3000 / 1 / 50 | 11/11 pass | none |
| 3000 / 1 / 100 | 7/11 pass | R2 needle, R2 width, R3, event repeat |
| 5000 / 5 / 50 | 10/11 pass | R2 needle |
| 5000 / 5 / 100 | 10/11 pass | event repeat |

R4 also remains open: the braked fixture widens from 477 to 627 km, but late closing is
15.6 mm/yr versus 14.9 mm/yr early (105%, required at most 75%). The brake still improves on
the 30.7 mm/yr late no-brake control. This is the already-owned M2 brake problem, not grounds
to alter the floor fix.

## Disposition and next step

The frame-stable classification is retained: it fixes the measured floor/classification
coupling with no physics-operator or threshold change and passes the direct and broad regression
suites. Do not tune the remaining strict-audit failures through floor constants. Next, diagnose
the 100 kyr R2/R3/event-repeat failures independently, then resume M2 brake selection on the
responsive M1 conveyor and rerun the full M3 matrix.
