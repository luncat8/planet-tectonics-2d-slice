## 2. Findings that changed the work (all measured, none guessed)

- **A v2 gap row cannot sit on a seam sample.** The fixture builder placed gaps
  at random; sample 67 of the pinned pack was both a gap and run 3's seam sample.
  v1 let the gap carry the boundary; the v2 canonical row zeroes `bnd`, so the
  seam vanished and the classifier re-signed a fallback neutral edge a frame
  later. The builder now never gaps a seam sample (`gap = rnd() < 0.02 &&
  !seamHere`, the roll still consumed, so every other sample is byte-identical
  in construction). A gap *inside* a run is still fine and still exercised.
- **A gap column's plate is a mapping decision, and the reader owns it.** v2 gap
  rows carry plate 0, which split plate runs (pinned: 15 runs instead of 12; the
  L7 case merged 29 instead of 7). `SEED.plates` now takes a column's plate from
  its widest *live* sample (a second widest-wins tracker in the box filter), and
  a column no live sample touches takes the plate before the hole (wrapping on a
  closed cut). `SEED.MAP` stays 2: the categorical widest-wins rule is unchanged;
  what changed is what a gap row contains. The `gapColumns` ledger line already
  books these columns.
- **A sealable window path has to be constructed, not drawn.** v2 proves
  `path.arcKm` against the polyline's own arc after six-digit quantisation,
  inside `2e-6` relative. The old fixture's fixed verts with an arbitrary
  `arcKm`, a latitude-10 parallel walk, and a naive equator walk all fail that
  proof (measured errors up to 1.56 m against a 0.24 m tolerance at 120 km).
  `windowPath` now walks the equator in ≤60° segments from lon 0, nudging the
  segment step by its own last digit until the walked arc and the arc the sealed
  bytes will carry agree inside 90% of the codec's tolerance. Measured:
  12 400 km dev 0 (err 13.4 m of 24.8 m), 45 000 km dev 0 (err 24.8 m of 90 m,
  wrapping past 180°), 120 km dev 13 m (err 0.11 m of 0.24 m); the 12 400 km
  case keeps `SEED.nCut === 158`.
- **The topology-shut timing is a re-measurement, not a mapping regression.**
  With the v2 pinned bytes, the first width-crush retirement at a subduction
  seam lands at frame 193 of the 199 the v1 bytes survived. `evAge` gates
  boundary reclassification (`js/columns.js`), not a crush; every frame-0/frame-1
  mapping claim (identity, ledger, classifier agreement) still holds at full
  strength. The check now asserts a shut topology for the first 190 frames and
  prints the measured first-change frame (experiments/section-seed.js, with the
  reason in the comment there).
- **Host flips on re-import are a derived bound now.** The checkpoint round trip
  flipped 3 host classes (cap was 2). All three are zero-crust columns that
  re-import with 2–4 m of bleed from a neighbouring sample — inside the
  thickness bound of the empty/oceanic boundary. The check now requires every
  flip to sit within that bound of a class boundary (zero total, 8 000 / 45 000 m
  felsic, sediment-dominance) instead of a magic count.
- **The moved-cut probe had to stay inside v2 law.** The checkpoint harness's
  quarter-column shift produced a negative `sKm[0]` (v2 requires the start at
  0) and a 1.5-cell widest span (v2's budget is *at most* 1.5 cells, and the
  shifted span landed on the wrong side of the float). It now shifts interior
  boundaries by a fifth of a column from `sKm[1]`, restamped by `SP.seal`
  (replacing `SP.checksum(SP.normalize(copy))`).
- **`pathChecksum` is derived, not stamped.** v2 bytes carry one checksum;
  `SP.pathChecksum(path)` is computed from the path. The B5 "path checksum"
  corruption class is therefore the path itself, refused by the stamp and the
  path law together. Recorded in the return package as an observation.
- **Kept-API sites needed no change.** `js/coupling.js`, `js/core-log.js`,
  `js/deposits.js` read only v2-kept exports; their harnesses went green
  unchanged (coupling 138, core-log 33, deposits 76). D5 stands.
