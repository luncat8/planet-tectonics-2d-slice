# 0.1.8 M2 — brake selection: the accumulated boundary shortening

## Scope

M2 asks for a brake measure that meets the arrest contract on a fixture whose orogen still
responds, chosen as the least persistent representation that does, then landed in `PLT.basal`.
This worklog records the measurement and the selection; the engine landing is the next step,
and the state it needs is named at the end.

## Method

`experiments/orogen-measure.js` on the M1 fixture: the prescribed two continents
(`check.twoContinents(seed)`), a 30 mm/yr prescribed closing force, 4000 frames = 200 Myr,
fit seed 1, check seed 5, 50 kyr/frame, `kBelt = 0.12`. `PLT.basal` is replaced by a hook that
keeps the engine's drive (`DRIVE * cD`) and adds one candidate measure:

```text
m = k * W * fb * close / vRef     fb = beltFel / hFelLand0 (capped at 2), close = -edgeRelN
```

- **instant** keeps the engine's own term with the swept k: `W = COL.beltW` this frame.
- **A** (derived, no new state): plateau felsic excess over the catchment, `/beltRise`.
- **B** (one scalar per edge): decaying memory of the widest belt the edge has built
  (tauUp 1 Myr, tauDown 50 Myr).
- **C** (added in this job): the same memory without the forgetting term.
- **D** (added in this job): the shortening the boundary has itself absorbed, in metres. The
  experiment books it from the same plate-witness walk the M1 record reports
  (`ACTIVE_RUN.shortening`). The engine's per-boundary form is the territory a conveyor
  retirement releases — the before/after pair gap that `COL.k4` already measures. On seed 1
  the released territory sums to 5238.3 km over the run against 5303.1 km of witness
  shortening (98.8%), so the local book and the global witness agree.

A, B, C and D switch the engine's own term off (`P.vColl = 0`) so no run carries two collision
brakes. Frame cost 1.9–2.2 ms/frame in every row.

Three harness corrections, all measured (the engine is untouched by M2 so far):

- **Pre-contact frames are not lost frames.** Seed 5 has exactly one frame without a collision
  site (t = 0, before the first pair reaches the floor at frame 90) and the brake-off control
  has it too, so it is not a brake property. The response and verdict `hold` clauses now count
  those frames (`r.pre`) instead of failing the whole run for them.
- **A witness column can be retired inside a live collision.** At 100 kyr/frame on seed 1 the
  3/4 witness column is consumed at frame 3555 and the whole remaining 445 frames read as
  "lost" (the run reports 3555/4000 live while the collision itself is fine). The harness now
  re-picks the nearest surviving column on the same plate and re-baselines, counting the
  re-pick frame as a gap. Measured after the fix: 3985/4000 live (the remaining 15 are
  re-pick gaps), belt 529 → 652 km, shortening matches closing at 98.5%.
- **The selected k meets both seeds.** The constant is fitted on seed 1 and then frozen and
  checked; a candidate is selected at the smallest k whose check also passes. Where the
  smallest seed-1-only k differs, it is printed (D: k 5e4 meets seed 1 at 68% but fails seed 5
  at 96% at 50 kyr; the selected k 2e5 is the smallest that meets both). `KFIX=<k>` freezes
  the constant for verification runs (no sweep, both seeds), which is how the 100 kyr check
  below was run.

## Why the others fail

- **instant / B / C** are all driven by the belt, and the belt grows only ~1.3× over 200 Myr
  (490 → 620 km) while the run's first quarter is already braked. The closing cannot fall 25%
  from its own first-quarter mean on the check seed. The brake is not weak: on seed 5 the
  brake-off control runs 16.9 → 29.8 mm/yr while the braked run holds 12.1 → 8.8, an 84%
  absorption; the contract's early window simply sits inside the brake's own engagement.
- **A** is structurally unsuitable on this fixture: the derived catchment measure stops
  growing when the belt saturates, and every coefficient that reaches the target has already
  sutured the collision below the live threshold (619–1219 live frames).
- **D** grows with the shortening the boundary has absorbed (one conveyor retirement per ~60
  frames releasing ~78 km of territory), so the brake keeps strengthening exactly as long as
  the collision keeps accommodating convergence. That is the R4 mechanism the plan named —
  a built-orogen measure, not this frame's shape.

## Selection

**D, accumulated boundary shortening, k = 2e5** (the same order as the engine's current
`P.vColl`), fitted on seed 1, verified on seed 5, and verified again at 100 kyr/frame with the
same frozen constant.

## Landing design (the next step)

- **State**: one scalar per boundary, `S.edgeShort` (Float64Array, metres). It rides the
  existing `edgeAge`/`edgeSlow` hand-off in `COL.k4` — the `histAge`/`histSlow` snapshots and
  the two plate-identity survival branches (`js/columns.js` 1206–1302) — and the birth resets
  (`js/columns.js` 689, 1083, 1281).
- **The increment**: at a conveyor retirement, add the released territory (the post − pre pair
  gap that K4 already computes for `COL.accrete`) to the surviving boundary's slot.
- **The force**: in `PLT.basal`, replace `lb = COL.beltW` with the accumulator (metres);
  `m = P.vColl * fb * -edgeRelN / vRef * lb` keeps its form and units.
- **Ownership**: the accumulator is local to the section and is **not** added to `COL.fields`,
  so the frozen `port/slice-format.js` v1 pack is untouched; a cut or import restarts it at
  zero, which the plan must state (the brake re-builds from the new boundary's own conveyor
  history; no mass rides on it, so the ledger is unaffected). It **is** a new checkpoint array
  — `js/checkpoint.js` enumerates every typed array in `S` — so the checkpoint VERSION must be
  bumped, with the old-version refusal and a round-trip fixture. `js/coupling.js`'s cut-import
  edge list (line 401) clears it with the other edge history.
