## Timing

The batch ran serially, alone, so the frame times are the cells' own: s3 12.706 / 16.915 ms/frame
(control / candidate), s1 12.037 / 16.224. Against the M5 host's serial banks (11.696 / 15.768)
this host reads **both rows within 3–9%** — the quiet-host reading the selection quotes (gate
green, 16.2–16.9 ms). The M6 batch's host — the "~30–35% above the M5 host" the report §5 names
— is a third host that read the same rows 27–38% high and crossed the gate for the candidate
(21.35–21.80). The probe's own overhead is 4.07–4.21 ms over the matched control on both quiet
hosts and 6.1–6.6 on the high one: the shift is multiplicative on both rows, so it is host
drift, and the gate crossing on the high host is the host's as much as the row's.
