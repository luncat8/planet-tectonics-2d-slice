## 1. Objectives & Scope

Milestone M3 establishes round-trip interoperability, full session checkpoint persistence, deposit catalogue generation with 3D $\to$ 2D projection, and vertical drilling stratigraphy:
1. **Deposit Catalogue & 3D $\to$ 2D Core (`js/deposits.js`):**
   - Deposit models for porphyry copper-gold, VMS, orogenic gold, roll-front uranium, sediment-hosted lead-zinc, kimberlite pipe, banded iron formation (BIF), and placer gold.
   - Host rock classification, blurred potentials, and snapshot computation (`snapshotSection`).
   - Deterministic 3D $\to$ 2D projection with circular cross-section reduction ($R_{2\text{D}} = \sqrt{R_{3\text{D}}^2 - y_{\text{out}}^2}$).
   - Stratigraphic vertical drill querying (`Deposits.drill`) and spatial probing (`Deposits.probe`).
2. **Session Envelope Checkpoints (`js/checkpoint.js`):**
   - Full session serialization (`saveSession` / `loadSession`) combining binary column runtime state (base64 encoded), mapper metadata, embedded `SlicePack` if present, and UI view/controller flags.
   - Atomic validation and robust typed-array recovery for JSON transports.
3. **Self Round-Trip Export (`SEED.exportSection` in `js/section-seed.js`):**
   - Export active column runtime world state into a valid `pgt-slice-pack` v1 object with all continuous fields, bed stratigraphy, deposits snapshot, and verified checksum.
   - Re-importing exported slice packs via `SEED.reconstruct()` matches initial world thicknesses within 6-digit cell quantization, closes mass ledgers to $< 10^{-15}$, and satisfies frame-0 isostasy identity ($|z - z_{\text{M}}| \le 10^{-3}$ m).
4. **UI Integration (`columns.html`, `js/section-pack.js`):**
   - Session Save (`sSave`) and Session Load (`sLoad`) buttons in the Slice panel.
   - File drag-and-drop and input file reader support for `.json` session envelopes.
   - `SectionPack.exportWorld()` convenience method.
5. **Validation Test Suite (`experiments/checkpoint.js`):**
   - 44 rigorous checks across 4 test suites: (A) runtime binary codec & atomicity, (B) session envelope serialization & corruption rejection, (C) deposit catalogue core & drilling queries, (D) self round-trip export & re-import isostasy/mass conservation.

## 2. Key Implementation Details

### 2.1 Deposit Catalogue (`js/deposits.js`)
- **Shared Deterministic PRNG & Hash:** Uses integer multiplication hashes (`(hash ^ (hash >>> 16)) * 0x45d9f3b`) incorporating world seed, pack checksum, cell indices, and deposit family keys.
- **3D Out-of-Plane Reduction:** Computes out-of-plane distance $y_{\text{out}} = (P(seed) - 0.5) \cdot 2 R_{3\text{D}}$. If $|y_{\text{out}}| \le R_{3\text{D}}$, the effective 2D radius is $R_{2\text{D}} = \sqrt{R_{3\text{D}}^2 - y_{\text{out}}^2}$; otherwise the body does not intersect the section slice.
- **Stratigraphic Intersections:** `Deposits.drill(world, xM)` returns all column crustal layers (sediment, felsic, mafic, oceanic, mantle) along with any intersecting ore deposit bodies and their depth horizons.

### 2.2 Session Checkpoints (`js/checkpoint.js`)
- Implemented lightweight `base64Encode` and `base64Decode` for binary Uint8Array payloads in browser and Node environments.
- Envelope schema:
  ```json
  {
    "format": "pgt-column-session",
    "version": 1,
    "created": "2026-10-03T...",
    "state": "<base64 encoded uint8array>",
    "pack": { ... },
    "mapper": { ... },
    "flags": { ... }
  }
  ```
- Gracefully handles both Uint8Array and Base64 string representations of `state`, and repairs plain-object array representations emitted by naive `JSON.stringify` on typed arrays.

### 2.3 Self Round-Trip Export (`SEED.exportSection`)
- Iterates over active columns ($k = 0 \dots N-1$), maps column horizontal spans $[x_0, x_1]$ in km, cell elevations $z_k$, water depths $w_k$, crustal thicknesses $h_k$, and layered bed stratigraphy.
- Emits fully conforming `pgt-slice-pack` v1 object including `checksum` computed via `SlicePack.checksum(pack)`.
