## 2. Correct C4

### 2.1 One guarded reader

`SectionPack.load` now dispatches coupling text to one `applyCoupling` path for paste, button and
file. That path:

1. requires a reconstructed section;
2. runs `COUP.parse` (wire checksum mandatory);
3. compares the message's stable path checksum to the active verified pack;
4. runs the complete mapping preflight before a state write;
5. applies and reports the one result.

The duplicated paste branches and their parse-error fallback into the pack reader are gone.
Unsigned, foreign-path and no-world imports are checked against both `S.hash()` and `S.recon` for
atomic refusal.

### 2.2 Geographic identity

A full pack checksum cannot identify a live path: thickness, time and source resolution change on
every re-cut. `COUP.pathChecksum` hashes the canonical geographic path and deliberately excludes
`cellKm` and sampled fields. The exact contract is now in `0.4.1-plan.md` §8.3. All twenty sequence
messages retain that identity while carrying different body checksums.

### 2.3 Beds are the authority

Matched columns reconcile each aggregate density class through stack operations:

- growth uses the ordered insertion primitive and receives the globe time as its bed age;
- shrinkage uses new `COL.removeClass`, shallowest matching bed first, so shrinking felsic crust
  does not consume the sediment above it;
- completely removed hosts invalidate their depth-resolved deposit, while deposits above a
  removed bed follow its shifted index;
- `COL.sums` derives all four aggregate caches after the edit.

An unmatched column's old volume is `retired`; its stack and hosted horizons are cleared, and the
message's three aggregate beds are built as `fresh`. Both are volumes, not counts.

`syncFel` / `syncMaf` / `syncSed` / `syncValid` travel with each Lagrangian column. They make the
own-kernel residual measurable at the next import. Newborn columns start invalid and therefore do
not masquerade as divergence. The checkpoint includes these arrays; its binary schema is version
2.

`S.recon.reconciled`, `diverged`, `fresh` and `retired` are cumulative m3 per metre out of section;
`divergedAtImport` is the current residual. `COUP.last` carries the per-import before/after,
added/removed and fresh/retired terms. Its identity is:

```
before + added + fresh - removed - retired = after
```

### 2.4 The gate now drives what it claims

The corrected section F starts from message zero, evolves the section by one cadence, applies the
corresponding globe message, then repeats twenty times. After every import it recomputes every
aggregate from the beds, measures retained bed identities and closes the identity above. The old
second loop that read the final `S.recon` twenty times is gone.

## 3. C3 owns K2

`SIM` now has one optional `kinematic` owner in front of the standalone K2 solve. A live coupling
activates `COUP.k2`; it assigns each existing section plate the width-weighted mean `vt` of the
message intervals under that plate's columns and writes the same rigid velocity to its columns.
K3 and all section geology remain the section's. Detach, reset, clear and checkpoint restore remove
the owner.

The gate prescribes 12 plates at 12 345 m/Myr, checks every `plU` and `colU`, checks zero-time is
still, then checks deactivation returns ownership to the standalone solver.

This is the kinematic half of C3. Following newly appearing message boundaries and sea datum is
still part of the remaining live-state pass; no report claims those two are done.

## 4. The §8.2 ladder and clock handshake

`js/coupling-link.js` is a transport-only channel:

1. probe `postMessage`, wait 250 ms;
2. probe the `pgt-coupling-link-v1` local-storage event bus, wait 250 ms;
3. select `clipboard/file` as a named ready rung.

The channel never bypasses payload validation. A coupling object delivered live is stringified and
sent through the same `COUP.parse` / path / apply route as paste and file. A throwing or absent
`localStorage` (common on restricted `file://` contexts) falls through rather than breaking boot.
The HUD always prints the selected/probing rung.

Clock messages carry the path identity, globe time, cadence and paused flag. A foreign clock is
refused; an unpaused clock without C3 kinematics is refused; a paused globe sets `dG = 0` in the
frame guard and the label reads `live · globe paused`. The cadence guard prevents the section's
next step from passing one message cadence.

## 5. Next step

Implement §8.5's `pgt-core-log` return path over `LINK.send('observation', log)`, but settle the bed
age contract first. The current engine deliberately contains two age conventions (imported rock
age and section deposition time), and an evolved stack can therefore be numerically non-monotone.
The globe-side rule says an accepted core log validates monotone ages. The next slice must add an
explicit age kind or one canonical formation-time conversion; silently sorting or clamping ages
would make a valid checksum over invented stratigraphy.
