## Steps

1. **Read the frame order again** (`js/sim.js`, `js/columns.js`): K2 velocities → `COL.transport`
   (`oldW = colW`, advection, `COL.floor`, sort + `gather`, `st.widths()`) → `COL.k4` (the quiet
   branch rescales beds by `oldW/newW`) → `onEvent`/`COL.finalFloor` **only on topology frames**.
   `S.widths()` is the Voronoi cell of the record's position (`js/state.js` l.298), so a
   territory change is exactly half the difference of the two neighbours' displacements — the
   identity the instrument checks against rather than assumes.
2. **`--quiet-identity`** added to `experiments/contact-audit.js`: pre-frame snapshot
   (`preX/preW/preTh/preFel/preMaf/preSed/preZr/preG`), a `COL.floor` wrapper that keeps the
   solve's own in/out positions (`floorIn`/`floorOut`, preallocated typed arrays, no allocation
   in the loop), C1 neighbour continuity through the same `MATCH` the report already builds, the
   exact width decomposition, C2 volume, the identity-corrected thickness
   `dhId = |hNew − hOld·wOld/wNew|` with its fel/maf/sed split, the drawn-surface split by
   population, an exceedance table, and the raster yardstick split by the same populations.
3. **Frame-integrity book.** A quiet frame whose record set changed is counted apart
   (`badFrames`, `badHits`, `badCount`, `badPairs`, `badCen`, its own drawn/identity maxima) and
   excluded from the certified books, with the kernel's own intents read from `COL.intent` in
   pre-K4 slot order, plus `SIM.onEvent` call counts and the ghost delta. The first bad frame is
   described in full so a later reader does not have to re-probe it.
4. **Probes** (`scratch/`, gitignored): `probe-quiet-frame.js 400 11 100` showed 31 of 400
   "quiet" frames change their record count; `probe-frame.js 1271 11 100 400` caught the
   retirement itself — a zero-crust ghost drained, its neighbour's width 34.2 → 73.2 km, its
   thickness 73.9 → 34.6 km, volume conserved to 0.21%, drawn elevation −5.9 km in one frame.
5. **`--drain-event`** added as a candidate detector: a `COL.drain` wrapper fills a separate
   `rSites`/`SITE_R` list with `siteKind = 'sliver retirement'`, deliberately **not** `dSites`,
   so R5 cannot read one consumption twice. Measured, not landed (see the report §5).
6. **Baseline re-run.** The four strict legs with the flag off (`--strict --detail`) stay
   **ALL PASS (13 checks)** and diff clean against `experiments/logs/0.1.9-quiet-strict-*.txt`
   (lines 1–21 and every gate line identical; only the `ms/frame` timing and the appended
   `--detail` block differ). The stale `0.1.9-contact-audit-{1,5}-{50,100}.txt` logs are
   pre-matcher 12-check runs and were **not** used as a diff base.
7. **Candidate strict legs.** The same four with `--drain-event --quiet-identity`: each
   `1 / 13 FAILURES`, R1 the only red, ratios 2.17 / 2.43 / 5.08 / 2.39 against a budget of
   1.25, saved as `experiments/logs/0.1.12-drain-event-strict-{1,5}-{50,100}.txt`.
8. **`experiments/acceptance.js` l.235 checked**: it runs those four legs and requires exit 0, so
   the corrected definition cannot land alone. Decision recorded in the report.
9. **32-world matrix**, 5000 frames, two variants per world (A `--quiet-identity`,
   B `--quiet-identity --drain-event`), 64 logs at
   `experiments/logs/0.1.12-{quiet-identity,drain-event}-<seed>-<kyr>.txt`, run `-P 2`
   (`nproc` = 2), ~20 min per pass. Run twice: the second pass after the frame-integrity wording
   was made precise ("had the event cadence called", "removed a ghost"), so every committed log
   matches the harness that wrote it.
10. **`experiments/quiet-identity-table.js`** parses both matrices, asserts the claims that make
    them a measurement (0 unmatched, 0 pairs beside a different record, the decomposition closes
    to 0 m, the advection law to <1 m, the raster split recombines to the gate's own yardstick,
    the populations partition, no birth/consume/accrete on a missed frame, every missed frame is
    a drain or a cadence call, a ghost change only on a drain frame, the censored population
    never sets the gate background) and prints the two tables plus the summary the report quotes.
    Output saved as `experiments/logs/0.1.12-quiet-identity-table.txt`.

## Two assertion bugs found by the matrix, both fixed

- The table compared the identity book's censored count (certified frames only, 0..1) with the
  audit's own `re-partitioned` count (all frames, 60..145). The right claim is
  `badCen <= censored`, with the residual reported: 2,882 of 2,883 censored observations sit on a
  record-set frame, 1 on a certified quiet frame.
- A ghost-count change is not evidence of a missed consume: the drained record **is** the ghost,
  so a drain frame removes one. The assertion is `badGhost <= drain` (1,790 of 1,801 drains), and
  the print says so.

## Reproduce

```sh
# from the repository root; the tables read the committed logs
node experiments/quiet-identity-table.js

# one world under each definition
node experiments/contact-audit.js 5000 1 50 --quiet-identity
node experiments/contact-audit.js 5000 1 50 --quiet-identity --drain-event

# the four strict legs, base and candidate
node experiments/contact-audit.js 3000 1 50  --strict --detail
node experiments/contact-audit.js 3000 1 50  --strict --detail --quiet-identity --drain-event

# the matrix (32 worlds × 2 variants, ~20 min at -P 2)
for s in $(seq 1 16); do for k in 50 100; do
  echo "node experiments/contact-audit.js 5000 $s $k --quiet-identity \
    > experiments/logs/0.1.12-quiet-identity-$s-$k.txt 2>&1; echo A $s $k exit \$?"
  echo "node experiments/contact-audit.js 5000 $s $k --quiet-identity --drain-event \
    > experiments/logs/0.1.12-drain-event-$s-$k.txt 2>&1; echo B $s $k exit \$?"
done; done | xargs -P 2 -I{} sh -c '{}'
```
