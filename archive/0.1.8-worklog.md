# 0.1.8 M2 landing and M3 — the absorbed-shortening brake in the engine

## Scope

M2 selected D, the shortening a C-C boundary has itself absorbed, at `k = 2e5`
(`archive/0.1.8-m2-worklog.md`). This job lands it in the engine as `S.edgeShort`, bumps the
checkpoint format, and runs the M3 acceptance matrix. The physics constant is the one M2
froze; nothing was tuned.

## What landed

- **State.** `S.edgeShort` (Float64Array, metres), one scalar per boundary (`js/state.js`).
  Ownership is per pair of adjacent records of different plates: cleared when the records
  stop being neighbours (`COL.transport`'s sort test, `COL.k4`'s hand-off), when a newborn
  takes the slot (`COL.rift`), and when the two sides become one plate (`PLT.classify`,
  where a suture lands). Not cleared on a state change: a braked collision that reads neutral
  for a few frames below `epsLo` keeps its memory, otherwise the brake would release and the
  collision restart from zero.
- **Hand-off.** It is deliberately **not** a `COL.fields` entry (the Lagrangian gather), so
  `COL.transport` carries it by hand with the same neighbour test, and `COL.k4` snapshots it
  in `COL.histShort` beside `histAge`/`histSlow` and hands it through the new `COL.handEdge`
  in both survival branches (the three-line copy that was duplicated twice is now one helper).
- **Increment.** `COL.released(st, count, k, pre)`: the surviving pair's gap after K4 minus
  the retired pair's gap before it (`COL.histGap`, taken in the K4 snapshot for intent-4
  boundaries only), floored at zero, added to the surviving boundary's slot in whichever
  branch handed it the history. Measured on the m2-check fixture: 78.18 km booked against a
  post-retirement pair gap of 82.09 km and a 3.91 km crush floor.
- **Force.** `PLT.basal`: `lb = S.edgeShort[i]` where `lb = COL.beltW` was; `COL.beltAt` is
  still called for the felsic factor `fb`; `P.vColl = 2e5` is unchanged. The form
  `m = P.vColl * fb * -edgeRelN / vRef * lb` is M2's hook with the engine's own W.
- **Checkpoint.** `js/checkpoint.js` `VERSION` 3 → 4 (the codec enumerates every typed array
  in `S`, so the record table grew by itself). A version-3 file is refused by its version
  word; the new record round-trips with the state hash.
- **Cut / import.** No slice-pack field: `port/` is byte-identical (`port-check` 15/15). A
  cut starts the accumulator at zero because the pack has no field for it; a C4 import
  (`js/coupling.js` `syncEdges`) restarts it at zero on every boundary — the boundaries it
  writes are the globe's, and the brake rebuilds from the section's own retirements. The
  state-presence list names `edgeShort`.
- **Harnesses.** `m2-check`: a fresh contact brakes nothing; the resistance equals
  `vColl·fb·close/vRef·edgeShort`; the conveyor books the released territory on the
  surviving boundary and nowhere else; every `invariants()` pass asserts that absorbed
  shortening sits only on live inter-plate boundaries (the 500 Myr def-planet leg carries it
  on 3–5). `checkpoint`: previous-version refusal and the new record's round trip.
  `coupling`: an import zeroes it even on a boundary whose age survives. `r4-check` now counts
  the fixture's pre-contact frame the way `orogen-measure` already did (seed 5 has exactly
  one, brake on or off). `orogen-measure`: `instant` re-creates the 0.1.7 belt-width term in
  the hook (it used to lean on `P.vColl`, which is now D), a new `engine` mode measures the
  landed brake through the same gates, and `KFIX` actually freezes the sweep (it was read
  before its own declaration, so the "frozen" M2 runs swept the full list and happened to
  select the first row). `contact-audit` prints the frame and x of the R1 site and away
  extremes (report only).

The brake changes the default planet's trajectory, so the four legs sample different events:
fewer of them everywhere, and the two legs that improved did so because their one red event
no longer occurs, not because a gate moved. The `5000/5/100` reds were traced with
`--detail` and `scratch/probe-m3-seed5.js` (not committed):

- **R1 1.30** (`siteDz` 2673 m vs `awayDz` 2051 m). Both extremes are frame 2364, 20 km
  apart (3616.0 and 3635.6 km): a conveyor retirement of a 40.7 km record on a thin plate
  (14.8 km crust, +20 mm/yr) against an 80 km block (−12.7 mm/yr) at a boundary that had
  turned from subduction to collision the frame before (`edgeAge` 0; the conveyor is keyed
  on the pair's closing motion, M1's design). The merged column's territory spans ~80 km;
  the audit's site window is `bucket × 2.5 w0 ± 1.5 w0`, anchored at the bucket's left edge
  (3515.6 km → window 3398–3633 km), so the event's own footprint 2.6 km beyond the window
  edge is what the gate reads as "elsewhere". The gate arithmetic is unchanged; the window
  anchoring is a definition question for the next plan.
- **R2 needle 2.23** at 1424.1 km, frames 3180–3183 (four samples). A 54 km column inherited
  at a margin beside a 17 km one; a 1–3 mm/yr trench reclassified the pair as a collision at
  frame 3180, `CRU.belt` spread it (54.1 → 45.8 → 29.4 km; ratio 1.1x by frame 3190) and the
  conveyor retired the thin record at frame 3195. `edgeShort` was 0 on that boundary: the
  brake had not acted there. It is the §2 onset-transient shape, one frame longer.
- **R5 repeat** 1 of 211: a birth 29 frames (2.9 Myr) after a death at the same site, outside
  the kernel's `P.evAge` (2 Myr) as every repeat on the 100 kyr legs has been.

None of the three is a hand-off defect (the invariants pass, the shortening sits only on
inter-plate boundaries, the ledger closes) and none is closed by a constant; §2 of the plan
already names the R2 definition question, and the R1 window anchoring joins it.
