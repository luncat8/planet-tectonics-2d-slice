## Live resources, not the immutable 3D catalogue

`js/ore.js` exports the single `COLORE` namespace in classic-script mode and is
registered at K8. It is DOM-free; buffers and scratch fields are preallocated.
`columns.html` remains file:// safe. Particle pages and shared `port/*` files are
unchanged.

The existing `js/deposits.js` catalogue and its grade-tonnage / economics ports
are untouched. Its API is `generateCatalogue(snapshot)`, not a live mining API.
An early assertion in the new bench used the nonexistent `DEP.scan`; that test
was corrected without adding an API or changing the catalogue.

A live record retains `(depCol, depLay, depCls, depGr)` and adds:

| field | meaning |
| --- | --- |
| `depVol` | remaining host-rock envelope, m2 per metre out of plane |
| `depPos` | marker position, fractional distance from the host's base |
| `depAg` | mineralization time on the geological Myr clock |
| `depId` | stable id across dense-table pruning and column sorting |
| `layOre` | per-bed class history, including exhausted resources |
| `depProduced / depExtracted / depRetired` | per-class resource-area accounting |

These envelopes are subsets of existing beds, never extra rock in `S.mass()`.
For each class, live + extracted + retired equals produced. Tonnage is
host-density-equivalent tonnes **per metre** of slice; the UI quotes **Mt/m**.
Grade is a frozen 0–1 game index, not a commodity assay, reserve estimate or
replacement for the 3D catalogue's priors.

## Factories and host selection

Continuous factories solve `o' = r(1−o) − kDecay·o` exactly. Birth and deposition
use exponential saturation pulses; fertility multiplies their doses. Quiet decay
uses the specified 500 Myr timescale. Arc / LIP potential writes formerly in K5
and the old additive sill-spill pulse were removed: K8 owns the continuous
factories, K4 owns birth pulses and K6 owns actual deposited-load pulses. Sills
supply a host, not another mafic factory update.

- **VMS:** oceanic birth / initial seafloor potential, on a buried, non-intrusive
  mafic horizon; an explicitly wet inherited seafloor remains eligible after
  continental cover arrives.
- **Mafic:** arrived plume or continental rift; basement / intrusive mafic host.
- **Arc:** overriding `trenchDist` 1..3 with ribbon recycling and closing speed;
  deterministic emplacement 3–8 km down, without consuming RNG.
- **Orogenic:** the collision belt and shortening thick roots, scaled by damage.
- **Basin:** wet sediment deposition and the thick wet-basin clock.
- **Placer:** the actual eroded arc / orogenic load follows K6's downslope routing
  and deposition; the host marker is a basal sediment lag. `colPla` records
  cumulative deposited placer equivalent, not a second mobile reservoir.

Delineation requires both a raw threshold and a one-cell-blurred local maximum.
Equal maxima use a stable column tie-break, except placer first prefers lower
terrain. Thresholds, host shares and thickness caps live in `params.js`.

A record's grade and mineralization time are not rewritten by later potentials
or imported fertility. Physical transport may split a record into a fresh id or
mix two moved envelopes with volume-weighted grade / position. This is material
transport, not reconditioning from a new potential snapshot.

Reset seeds potentials only; the first K8 may record hosts even at zero geological
dt. Subsequent paused K8 calls are idempotent. This is metadata bookkeeping, not
an advancing factory or geological clock. Reconstructed cuts explicitly scan
imported potentials after laying and auditing their stacks.

## Stack lifecycle and explicit extraction

`layOre` follows insertion, compaction, sorting, transport and fresh-stack resets.
Insertion publishes its actual receiver slot / existing base via reusable COL
metadata. Deposit transport follows that slot, not an assumed surface cap.
Growth / compaction rebase marker positions; partial erosion / removal retires
the lost resource share, and a destroyed host is pruned at K8. Capacity deferrals
are counted and retry without marking an uncreated resource. Transport overflow
retires a named resource share instead of silently losing its budget.

`ORE.extract` accepts the live section state, a stable id and finite positive
area. It clamps to remaining resource and real host area, removes exactly
area / column width, credits that bed's original lithology in `ledCons`, retires
collateral resource shares, and refreshes sums / elevation / local slopes.
Volcanic extraction trims only written edifice stock, not molten transit.
An exhausted bed keeps its class history and cannot instantly refill from an
unchanged potential.

Matched C4 growth preserves existing resource identity, grade and time. C4 host
removal retires its resources; an unmatched fresh stack clears old masks and
invalidates its old pointers. The new tests are **deposit-only C4**: active-vent
C4 reconciliation remains the separate M5 follow-up.

Checkpoint **VERSION 8** includes budgets, positions, ids and bed histories;
a v7 header is refused atomically, with no legacy reader. Reset, restore and
reconstruction require a fresh explicit mining selection before ids can be reused.
This extends the existing codec; it does not implement M4's general page chrome
or diagnostic expansion.

## UI and new validation

Press **d** or click **deposits** for six class glyphs and a list ranked by class,
then remaining tonnage. The selected stable id survives ranking and pruning.
**Extract 10%** and **extract remainder** are explicit, irreversible actions.
The probe reads the same live host resources. Glyphs use the body's actual
profile / layer stretch and periodic copies; repainting cannot mutate the model.

The list rebuilds on user actions and the existing 2 Hz HUD cadence, not in the
raster. Raw / missing cuts cannot mine a hidden world. Typing controls and held
keys do not toggle it. Host-scoped start / stop removes listeners, and switching
an empty cut back to a planet re-enables its button.
