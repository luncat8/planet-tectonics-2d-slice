# 0.4.1 M5 source-review follow-up

**Date:** 2026-10-05  
**Status:** source re-audited; confirmed defects below are corrected on the current branch. Earlier M5 reports remain historical snapshots, not evidence for current behavior. This follow-up does not close the separate R4 acceptance gap.

## Confirmed gaps corrected

- **Age-to-fan update:** `COUP.apply()` detects crust-age changes above 0.01 Myr and calls `COL.lidFan()` once at import. It does not call `COL.initFanT()`, so it refreshes the age-defined lid without clearing deeper fan thermal anomalies; plume entities remain intact. Regressions verify the lid changes, a deeper anomaly survives, and plumes are retained.
- **Boundary follow and new ribbons:** message plate-run `bnd`/`pol` events are projected from their interval-end arc positions onto section edges. Unreported seams return to neutral/none on import, unchanged pairs preserve edge age, and trench distance is recalculated. A newly changed subduction crossing creates/reuses a ribbon at the physical midpoint of the section edge and keys it to the overriding plate, matching `COL.consume()`'s ribbon ownership. Crossings that cannot be represented are booked in `bndCollapsed`/`bndLost`.
- **Live C3 reclassification:** `PLT.k3()` now forwards the kinematic-ownership flag to `PLT.classify()`. While the adjacent plate pair is unchanged, K3 retains the imported boundary type and polarity instead of reclassifying a quiet section-relative velocity as neutral. The post-K4 and post-event classification paths carry the same flag. A regression drives an imported subduction boundary through K3 and the post-K4 classification path with zero relative normal speed.
- **Open-path joins:** geographic joins distinguish closed rings from open windows, so a window cannot inherit geology through a wrapped endpoint. Open-window edge projection keeps the source arc scale and leaves its terminal edge unset.
- **Sea datum:** `seaLevel` resets to zero, wet classification uses that datum, and a coupling import follows the incoming level while preserving displayed elevation. Checkpoint schema is v3.
- **Observation retry and reset:** the core-log cadence commits only after a successful live send or successful manual placement. A failed send or unavailable output leaves the observation due for retry. `SectionPack.clear()` **does reset** the core-log side table; a regression confirms clearing makes baseline records due again.
- **C1 host validation:** `experiments/smoke.js` exercises engine and section mode through a nested element host with duplicate control IDs, verifying controls, canvas, classes, and listeners stay scoped to that host. `columns.html` explicitly starts the page with `COLSIM.start(document)`; modules do not self-start.

## Remaining limits and review decisions

Boundary events are projected onto the section's existing column-pair topology; this change does **not** rewrite `colPlate` intervals or perform a new plate-cap merge during C4. A crossing landing inside one section plate is counted as unrepresentable (`bndLost`). If C3 is expected to split/merge section plate records from every incoming topology change, that needs a separate topology-capacity design and acceptance test. When a local topology change creates a different adjacent plate pair, its edge starts neutral until a later snapshot supplies the globe's boundary code.

A paused import can leave `edgeRelN` stale until the next positive-time K3. This is intentional: at `dt = 0`, K2 does not slave new velocities, K3 is a no-op, and K4–K6 return before consuming the value; the first active frame prescribes K2 velocities and recomputes `edgeRelN` in K3 before later kernels. The regression poisons the paused value, confirms it is not refreshed in the zero-time path, then confirms active K3 refreshes it. No stale-value consumption was found, so no extra paused-import mutation was added.

No real-browser manual run was performed; compatibility evidence remains the classic-script VM page harness plus paste/file-path tests. The distinct **R4 verdict remains NOT MET**: `experiments/r4-check.js` reports belt width decreasing from 529 km to 88 km and closing speed rising from 16.9 to 32.1 mm/yr. Its three mechanical checks pass, but its diagnostic acceptance (a widening belt and falling closing speed) does not.
