# 0.2.0 M2 — write-back and the visible edifice

Plan: `0.2.0-plan.md` M1/M2; physics: `0.1.0-design.md` §§1.5, 5, 6.
M2's dedicated acceptance passes **73 checks**. Reviewed M1 passes **38**, M0 passes
**25**, and the real 16-vent body fixture stays below 6 ms. This is not a claim that
the entire series is accepted: extended contact runs retain the R2/R5 reds below.

## M1 review and corrections

- The toy's `tauCool` name collided with secular cooling in `params.js`. The toy now
  uses `toyCoolSec = 1800` seconds; geological `tauCool = 2500` Myr is unchanged.
  After 900 seconds a fresh cell is at 0.60653066; another 100 seconds freezes it.
- Fill the vent before testing `Vdie`, so fresh supply resets the geological idle
  interval. Orphan cleanup runs even when the plate clock is paused.
- Clear a consumed column's `volc` inverse before redirecting its vent. Sorting no
  longer reconstructs `venCol` from that stale inverse and resurrects an orphan.
- A shield belongs to the plume's actual owning column, not every column within
  `w0` of its centre. The neighbouring province gets fissure style.
- Packet velocities use an independent, checkpointed `venRng` word per vent,
  seeded with a pure hash of the run seed. FX cannot consume future plate / plume
  RNG draws. The M1 bench verifies this with a real scheduled blast.
- `Vch`, `Vbirth`, `Vdie`, `tauVent`, the boundary conversion and drain law were not
  retuned. Seed 1 still births from natural supply: after 200 Myr there are 3 opened
  slots, 0 alive vents, 0 idle throughput and 0 lost melt. Reuse now works rather
  than retaining every frozen pile as an immortal vent.

## One mass owner, retained geometry

`toyH` is the height map; `toyFz` is its solid part, retained for drawing.
`toyAsh` tracks the molten tephra fraction independently of the last surface colour.
Slump transports solid, molten lava / ash and heat without turning written rock
back into melt.

Freeze queues lava / ash in `venLava` / `venTephra`; landing queues tephra. Each K7
drains those outputs exactly once via `COL.insertVol` on the owning column. Molten
material and airborne packets may remain; the retained solid shape owns no mass.
`ERUPT.mass()` and `S.mass()` count only chambers, molten material, packets and
unwritten outputs as mafic melt. Actual beds are counted normally.

The boundary is shared by feeding, write-back and the ledger:

- `toyCellX = 2343.75 m`, `toyCellY ≈ 247.46 m`;
- `toyCellM2 ≈ 5.800e5 m2/cell2`;
- inserted thickness = queued cells2 × `toyCellM2 / colW`.

Transfer moves the original production entry from mafic melt into lava / tephra,
like the existing chamber-to-sill path. Ordered insertion, compaction, wet flags,
formation timestamps and deposit-slot shifts remain `COL`'s responsibility. The
full-stack rejection path was corrected to book section area on the passed state,
not thickness on the global state.

K7 refreshes sums, `hDraw`, wetness and local slopes. `z` changes only by the
transfer's buoyancy increment; Moho therefore changes by that rise minus the added
thickness. It does not re-run erosion or create neighbouring crust.

Record fields:

| field | meaning |
| --- | --- |
| `venCol` | active vent owner; −1 when inactive |
| `venEdCol` | retained shape owner, including dormant edifices |
| `venW`, `venH` | toy-derived contour width and peak height, metres |
| `venEdV` | remaining written stock, m2; not another ledger reservoir |
| `venToyIn`, `venToyOut` | cumulative supplied / handed-over toy cells2 |
| `venLast` | last feed time on the geological clock, Myr |
| `venStyle` | style fixed at birth |

Death now uses `tauVent` below `Vdie` **alone**. Retirement freezes / settles /
writes remaining material, returns the chamber dribble and preserves the cold
shape. Same-column rebirth reuses that shape; different-column slot reuse resets
its geometry but leaves its physical beds untouched. K4 remaps both owners. A
redirected vent carries only transit from its consumed source and may adopt its
destination's dormant geometry; K4 already owns the source rock's fate.

K6 callbacks trim the record only after actual volcanic erosion and hide relief
after actual sediment deposition. Erosion cuts the summit before low flanks;
burial does not consume the buried stock or pending melt. No second erosion ledger
is introduced.

Checkpoint **VERSION 7** includes all queues, ash, ownership, records and packet RNG.
Version 6 is refused; no legacy reader was added.

## Visible acceptance

`render.js` batches toy faces by lithology and draws molten glow from the molten
fraction. It clips against the body's actual profile, handles periodic copies and
derives sparks / ash halos analytically from the existing packet buffers. Changing
`venW` / `venH` cannot invent a different cone; changing the toy can. Rendering does
not mutate the model or camera. The cone probe resolves its owning column even
when its flank crosses a LUT interval, then reads the ordinary volcanic bed and
its formation timestamp.

Both prescribed episodes run through the real `MAG.add` / `MAG.k7` meter: 150 cells2
supplied at time 42 Myr with geology paused, 175 metered 14400-second frames, then
four 1800-second cooldown frames. Chambers were not enlarged for the test.

| episode | default-window width × height | worst per-lithology ledger error |
| --- | --- | --- |
| effusive | 27.00 × 10.05 px | 1.09e−15 |
| explosive | 27.00 × 10.05 px | 2.94e−15 |

Each transfers approximately 8.7000079e7 m2, leaves no pending mass after cooling,
reads back the intended bed / formation time, and retains the same geometry without
double-counting it. Other checks cover mixed phases, once-only writes, buoyancy /
Moho / neighbour isolation, rank / capacity / deposit shifts, paused-clock hot and
airborne retirement, wrap / sorting / reuse, orphan loss, same-column rebirth,
destination adoption, actual K6 summit erosion and routed one-hop sediment burial.
Complete burial preserves written stock; invalid zero-height records clear without
consuming that rock a second time. Active checkpoints resume bit-identically for 1000 frames at two zooms.

`experiments/edifice-visual.js` is an **optional** native Canvas2D diagnostic, not a
browser dependency. It produced inspected scene / close-up images in ignored
`scratch/`: 3590 overlay-changed pixels, **zero changes more than 1 px below the
profile**, and 3 passing native checks. Overlay best 1.808 ms across five batches;
this is a diagnostic measurement, not a browser end-to-end fps claim. To reproduce:

```sh
npm install --prefix scratch/canvas --no-save --no-package-lock @napi-rs/canvas
node experiments/edifice-visual.js
```

### Contact: scope explicit, limits unchanged

The default contact audit still runs both clocks with the original gates.
`--tectonic-only` explicitly pauses the eruptive slider for the plan §0's isolated
tectonic contract; it does not silently change the default or loosen any limit.
Baseline comparisons used `git archive` of original HEAD
`4a2e4010d006c8c1d97d935d077dd1366fdc07f4`, not a different branch.

| frames / seed / kyr per frame | M2 combined clocks | M2 tectonic only |
| --- | --- | --- |
| 3000 / 1 / 50 | 12 pass | 12 pass |
| 3000 / 1 / 100 | 11 pass; R5 repeat 1/325 | 12 pass |
| 5000 / 5 / 50 | 12 pass | 12 pass |
| 5000 / 5 / 100 | 10 pass; R2 needle 2.03, R5 repeat 1/265 | 10 pass; R2 needle 1.65, R5 repeat 1/238 |

Original HEAD's combined `3000 / 1 / 100` passes all 12; its `5000 / 5 / 100`
already fails R2 (1.65) and R5 (1/238), exactly matching M2's isolated tectonic leg.
Write-back changes real crust and therefore the combined trajectory: the seed-1 R5
red is new on that leg, while the seed-5 failures are not an all-green baseline.
Separating the packet RNG did not change these combined contact verdicts.

All matrix legs pass R1, the built-belt width clause, R3, stack order / capacity,
draining stock and finiteness. All reported R5 repeats are outside the model's own
2 Myr memory (20 frames at 100 kyr/frame), though inside the audit's fixed 40-frame
yardstick. No contact law, memory interval or threshold was changed to hide them.
The whole-series contact acceptance remains open.
