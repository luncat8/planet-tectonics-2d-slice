## Changes

- `experiments/pt-heat-tail.js`:
  - `stencil` probe: M1's `spread` with the placement set widened to the 3×3 node block of
    the gather stencil (`rad` 1; `spread` is the same code at `rad` 0 and keeps M1's placement
    order exactly).
  - `relaxw` / `subgrid` probes: sub-grid relaxation of passive host parcels toward the
    bilinear field at retention `exp(−d·kappa·dt/m)`, `--scope dep|solid`; `relaxw` books the
    net correction as an explicit source `R` beside the wall (never into `S.wall`) and reports
    the operator-only ratio and `R/wall`; `subgrid` scatters each parcel's extensive correction
    over the covered nodes of its stencil and takes it back through the adjoint weights, booking
    whatever does not return.
  - `--seed`, `--kyr` (one matrix cell); `--assert-m2` (the re-banked cell, fingerprint
    6191250240167390, 3 transfers); `latentBook` (the identity residual over the larger of its
    two books) and `latentAbsMax` beside the plan's floor-1 metric; `outsideFrames`, the hottest
    parcel record with its field; G5's held-back residence now integrates over the fluid substep
    (bitwise-neutral at 50 kyr, where a frame is one substep).
- `experiments/pt-heat-matrix.js` (new): the M2 clock/seed matrix; children of the runner,
  per-cell gates on every frame, first cell repeated bitwise, `HEAT_MATRIX_OUT` bank.
- `experiments/pt-heat-tail-check.js`: the M2 section — the re-bank's grid-coupled readings
  equal the M0 bank bitwise and its identity closes; the four M2 probe rows with their
  outcomes (refusals reported, not asserted, because one probe saturates the pool).
- `0.3.2-plan.md` §M2 rewritten as a specification (latent remedy, tail re-measurement,
  matrix gates, re-bank); `AGENTS.md` harness list; `roadmap.md` 0.3.2 status;
  `findings-pitfalls-skills.md` M2 section.
- **No change to `js/pt/`, parameters, pages, routing eligibility or shipping fingerprints.**

## The subgrid banks were re-measured

After the matrix, the subgrid probe's two inline 3×3 stencil-weight loops (scatter, reaction)
were folded into one helper, `covered()` — the same covered-node set and the same formula,
`E_k += e·W_pk/ΣW` and `ΔH_p = −Σ_k W_pk E_k / w_k`. It is **not bitwise-neutral**: `relaxw`
(which does not use the stencil) reproduces its 20 Myr smoke exactly (3789795940337738), but
the subgrid smokes moved (dep 7146383824004358 → 8194974861906080; solid 4298233847507753 →
5287381679657138) with the readings differing in the last digits only (relaxGross
1261.1779726113891 against …894). Sixteen association orders of the two sums were tried
against the dep smoke; none reproduces it. The pre-refactor code had never been committed, so
the first banks cannot be regenerated. Both subgrid cells were re-run from the code as it
stands (concurrently, before the series) and replace the first banks:
