# 0.4.1 review and M3 checkpoint foundation

Reviewed checkout `9bf6a4b`. It is the only commit visible in this checkout, so the review used
the M2 report, source and acceptance harnesses rather than a parent diff.

## Review fixes

- `SEED.measure` now commits window/scale/count/tail only after a cut passes its fit checks.
  Previously a refused cut changed the active mapper metadata even though `S.hash()` stayed put.
- Reconstruction calculates the candidate cooling state before touching `SIM`; a layout refusal
  no longer changes the current world clock.
- `SectionPack.loadPack` preflights fit before replacing the active pack. An unplaceable cut may
  open as the raw strip on an idle page, but cannot replace a section already on screen or on the
  clock. A successful replacement stops the old clock before the new section appears.
- A JSON primitive such as `null` is refused with a useful message instead of escaping during
  normalization; existing sections remain intact. Refusal state is not cleared during page boot.
- The cut readout includes the section seed and mapping version. An accepted-but-unplaceable pack
  is labeled as raw/unreconstructed rather than borrowing stale ring/window mapper labels.

## Development

`js/checkpoint.js` begins M3 with `Checkpoint.save()` / `Checkpoint.load(bytes)` for the column
runtime. Adapted the envelope from upstream `js/checkpoint.js` at `d909476`: 64-byte header,
float64 scalars, 16-byte typed-array records and 8-byte-padded blocks, with local magic/version.
Stores every `S` typed array and numeric field, `S.recon`, simulation clocks/event cadence, seed and
slider rates, and all RNG words including the cached Gaussian spare. Derived mantle modes/time are
rebuilt from the saved seed and clocks; slab readiness is invalidated for the next active step.
Load validates the header, capacities, array table, finite values, seed, sliders, RNG and entity
counts before writing any live state. Unaligned input views are copied; fixed state-array identities
are retained.

This is a **runtime checkpoint API**, not yet a full section-page session capture: source pack,
mapper identity, view, controls and spin baseline are not included. There is no UI button or particle
checkpoint. The deposit catalogue and self-export through the shared cut codec are also outstanding;
M3 is not complete. Like the upstream envelope, this format does not checksum arbitrary payload
bytes; schema changes require a version bump.
