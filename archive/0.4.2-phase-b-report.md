  `SectionPack.decodePack` is `SP.decode`; `loadPack` goes `SP.encode` → `decodePack`
  (the codec's own text form, so no local coercion of raw objects);
  `js/checkpoint.js`'s embedded pack is proven by `sp.decode(JSON.stringify(obj.pack))`

  make → seal → encode: `SEED.exportSection` (aggregated live-count plate table with

  `SP.setGap`; `SP.hostCode`; polarity only on subduction; non-empty `rotModel`)
  and the synthetic fixture builder (`experiments/pack-fixture.js`), which now
  builds only sealable packs. Kept-API call sites (`SP.round`, `SP.EDGE`, `SP.HOSTS`,
  `SP.latLonAt`, `SP.azimuthBetween`) stand as they were; D5 stands — the private
  path-hash code was *not* replaced by `SP.pathChecksum`.

## 3. Sync audit (B6, 0.4.0 §2.6 style — one decision per touched concept)

| concept | decision | note |
| --- | --- | --- |
| `pgt-slice-pack` codec | **adopt upstream, byte-identical** | `port/slice-format.js` + fixture; local edits never; ambiguities return through the globe's 0.8.0 §5 procedure (D6) |
| manifest | **adopt upstream shape** | `pgt-port-manifest` v2 with role pins; `port-check.js` asserts it on this side |
| host classification | **adopt the codec's law** | `SP.hostCode` is the one classifier a pack is validated against; `js/deposits.js`'s `DEP.hostCode` keeps the same thresholds (8 000 / 45 000 / sediment-dominant) for live engine floats — two readers of one law, measured equal on the exported integers |
| gap row | **adopt upstream semantics** | canonical row is the codec's (`SP.setGap`); the section-side consequences are mapping rules, below |
| gap column's plate | **keep-local (mapping)** | a v2 gap carries plate 0 by canonicalisation, not a plate of its own: the section reads a column's plate from its widest *live* sample, else the plate before the hole (`js/section-seed.js`); booked by the existing `gapColumns` ledger line |
| plate table | **adopt upstream** | one row per id, live-sample counts, Euler poles where the writer has them; the ring's self-export writes zero poles (its speeds are the `vt` field) |
| deposit catalogues | **keep-local, frozen** | relocated `port/` → `js/data/` (D2); no backport in either direction; the draws-fixture provenance (`d909476`) is a historical extraction pin, asserted as such by `experiments/isomorphism.js` |
| checkpoint session envelope | **keep-local (D4)** | unchanged format; only its embedded-pack reader follows the codec |
| Earth bundles | **declared divergence, temporary** | retired at B-a; restore is B-b through a globe v2 writer, per bundle; the frozen Python bake is never the path |
| `pathChecksum` | **adopt as derived identity** | used for reporting (this package, `port-check`); D5 stands: no local hash code was replaced by it |
