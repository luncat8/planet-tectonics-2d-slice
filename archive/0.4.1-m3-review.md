## 2. Findings

1. **The deposit catalogue was not the counterpart's** (high, fixed). Upstream's bodies are a
   pure function of `(seed, version, tileIndex, family, ordinal)` with 40 keyed draws, three
   families, per-commodity grades and a counted rejection ledger. The commit's version (`248`
   lines) hashed a locally invented string key, drew with `Math.random`-shaped locals, carried
   six families with one grade per body and no tile index. "The same body in two projects" —
   the whole point of `0.4.0-sync-plan.md` §2.5 — was not true. Rewritten onto the upstream
   core (`487` lines), and `experiments/deposits.js` replays the counterpart's own numbers.
2. **No fixture, no priors** (high, fixed). §2.5.1 asks for the shared core byte-identical with a
   checked-in `fixtures/deposits-draws.json` both sides assert; §2.5.2 for
   `data/deposit-models.js` / `deposit-economics.js` shared-identical. Added
   `js/deposit-core.js` (the upstream functions, verbatim),
   `experiments/make-deposits-fixture.js` and the fixture it generates from a pinned checkout
   (`d909476`, sha256 recorded in the file), plus the two shared data modules
   (`port/deposit-models.js`, `port/deposit-economics.js`, LF, byte for byte).
3. **Two owners for one host law** (medium, fixed). `js/section-seed.js` classified the pack's
   `host` field itself and could disagree with the reader. It now calls
   `Deposits.hostCode(...)`; `P.hOro` (45 000 m), which the law reads, was missing from
   `js/params.js` and is added between `hOceanic` and `hCollapse`.
4. **The page never loaded the shared modules** (medium, fixed). `columns.html` now loads
   `port/deposit-models.js`, `port/deposit-economics.js` and `js/deposit-core.js` before
   `js/deposits.js`; `experiments/lib.js`'s `scriptOrder()` therefore keeps node and the browser
   identical.
5. **Drill and probe disagreed with the reduction** (medium, fixed). `drill` queried
   `col`-ownership and `probe` ignored its radius depth band; both now use the projected
   footprint, and `drill` is a vertical line at an arc coordinate (beds plus the exact depth
   interval each body is crossed over).
6. **Three checks in `experiments/checkpoint.js` could not fail** (medium, fixed). §A's
   `fnvBytes` assertion was `x === y || true`; §C ran against the stub's array API and asserted
   the stub's own contract (`cat1.length`, `projectedRadiusKm <= radiusKm`), which passed while
   the thing it named was absent; §D's "identical thicknesses and ages" was a hard-coded
   `< 15 m` and the 1 000-frame gate ran 100 frames. §C is rewritten against the current API
   (tile vs scan identity, JSON round trip, tamper refusal); §D now derives its bound from the
   pack's own arc quantum (six significant digits ⇒ ≤ 50 m at the ring's end) and shows the
   bound is not vacuous by shifting a cut a quarter column (6 708 m vs 11.4 m).
7. **The drift gates did not gate** (medium, fixed). `port/deposit-models.js` and
   `port/deposit-economics.js` were not listed in `port/PORT.json` (so `port-check.js` failed by
   design), and `experiments/smoke.js` asserted that *only* `port/slice-format.js` may be a port
   script. The manifest now carries both files with their sha256 and upstream path; smoke
   compares the page's port scripts against both the directory and the manifest.
8. **The worklog overclaims** (low, corrected). `archive/0.4.1-m3-worklog.md` describes a
   catalogue, an envelope (`pgt-column-session`), `SEED.reconstruct()` and a bed-carrying export
   that the commit does not contain. A correction note at the top of that file points here; the
   original text is left as written.

## 3. What M3 does not do yet

- The catalogue is not wired into the page: no drill readout in the Slice panel, no deposit
  overlay in the section view. §M3's gate is satisfied at the API level
  (`experiments/deposits.js` §D–§F); the viewer is M4/M5 work (`0.4.1-plan.md` §4.3.7).
- `Checkpoint.loadSession` mutates the object it is handed (it re-types the pack's arrays in
  place). The save path never hands it a live object, so this is a note, not a defect.
- `SEC.baseline()` averages mass and `z` over all columns including ghosts. Kept: the readout is
  the whole state's mean at both ends of the window, and it says how many records it saw.
- The seam-wave/surface-point freeze (`0.4.1-plan.md` §3.3.1) is a cutter-side decision on the
  globe's repository; nothing here can settle it.
