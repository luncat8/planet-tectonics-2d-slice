# 0.9.0 M2 — real-browser acceptance

2026-10-19. **Local M2 browser gate passed.** This completes the browser item left open in
`0.9.0-M2-library-host-worklog.md`; it does not accept the globe adapter or open a live channel.

## Implementation

Added `experiments/library-browser.js`, an optional Playwright-core driver using a local
Chromium executable (`CHROMIUM_PATH`) or the npm-packaged `@sparticuz/chromium` binary.
It opens `library.html` directly via `file://`, without a server, at 1440 × 1100, and drives
the actual host buttons. Test dependencies remain in ignored `scratch/`, outside the page
runtime. No engine, port, fixture, or page changes were necessary.

The browser exposed a distinction the VM does not need to model: `COLSIM.frame` increments
on paused animation frames too. Pause assertions therefore compare geological time; the
single-step assertion measures its synchronous button handler's frame and time deltas.
The expected time increment comes from the logarithmic geology slider mapping, not an
assumption that slider value 1 means one year. The measured increment was
0.0010053123782720848 Myr, exactly the configured rate.

## Reproduction

With a system Chromium and `playwright-core` on NODE_PATH:

```
CHROMIUM_PATH=/path/to/chromium NODE_PATH=./scratch/browser/node_modules node experiments/library-browser.js
```

In this minimal sandbox, install optional tools and extract the packaged Linux libraries:

```
npm install --prefix scratch/browser --no-package-lock playwright-core@1.64.1 @sparticuz/chromium@153.0.0
node -e "require('fs').writeFileSync('scratch/browser/al2023.tar',require('zlib').brotliDecompressSync(require('fs').readFileSync('scratch/browser/node_modules/@sparticuz/chromium/bin/al2023.tar.br')))"
mkdir -p scratch/browser/al2023
tar xf scratch/browser/al2023.tar -C scratch/browser/al2023
LD_LIBRARY_PATH=$PWD/scratch/browser/al2023/lib NODE_PATH=./scratch/browser/node_modules node experiments/library-browser.js
```
