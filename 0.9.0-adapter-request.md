## 3. Adapter scope requested of the globe

1. **Construct and dispose the section.** Load the slice's canonical classic-script set in
   dependency order, from a separately available slice tree, not vendored copies. Use
   `columns.html` / `library.html` as the script-order reference. The shared `SlicePack` and
   `CoreLogFormat` modules load once per page, not once per engine. Build the controls in a
   host element, preferably inside a ShadowRoot to isolate ids. Supply host-local CSS.
   Keep one active section: the current library is a singleton, not a multi-instance factory.
2. **Choose the geographic cut.** Keep the map picker, line, 3D view and camera on the globe
   side. Refuse equal/antipodal endpoints. Snap perpendicular to the nearest boundary or
   along local plate motion using exported fields as a display-side computation; do not
   change the kernels to satisfy a picking gesture.
3. **Deliver snapshots and clock.** Construct verified `pgt-coupling` v1 messages, apply
   once per accepted handoff through `COLCOUPLING.apply(msg)`, and inspect its receipt.
   Deliver `COLSECTION.applyClock(clock, rung)` with the matching path, world time, pause
   bit and agreed cadence. Do not confuse stopping calls from the globe with pausing the
   section: its own animation loop runs until explicitly paused or stopped. Preserve the
   section's mode/staleness indicators and refusal messages.
4. **Display the cut-plane overlay.** Draw a quad strip coloured from the section's palette,
   not a second section physics implementation. The geometry/palette delivery surface is
   an explicit review item (§4), not permission to read internal arrays.
5. **Return observations for display only.** Use `pgt-core-log` v2 with the
   `section-lith-1` vocabulary. Globe importer order stays parse/validate into temporary,
   compare identities, commit atomically, redraw. Foreign paths refuse; a different
   `packChecksum` is stale-never-current, archive only after confirmation. Preserve the
   observation delivery's commit-on-acceptance rule; never feed records into a kernel.
6. **Keep the fallback.** The hosted function-call rung is the eventual target. Until the
   pair gates and review allow it, manual clipboard/file remain the contract. A hosted UI
   rehearsal is not permission for continuous C3+C4 reconciliation or a new transport.
