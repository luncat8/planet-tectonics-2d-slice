# 0.1.0 — Project plan

Implements `0.1.0-design.md`. Self-contained: a fork can execute this plan with the design
document alone. CPU JS + canvas only; every phase ends with a page that draws something new
and with its `experiments/` checks printing PASS.

## 0. Conventions

- Runtime per `AGENTS.md`: classic `<script>` tags, file:// friendly, no build, tabs,
  no allocation in the frame loop, `module.exports` guarded so every file runs under node.
- One unit system (design §9): m, Myr, m/Myr, 1/Myr; the eruptive clock and the slider
  ranges are the only seconds/yr quantities and are converted at the boundary. Never put a
  per-year rate into `params.js` next to a Myr rate.
- Headless rule: `geom`, `state`, `sim.step` and every kernel are DOM-free, and the body
  raster writes into a caller-supplied buffer (`render.body(st, px, w, h)`); only
  `render.present()` and `ui.js` touch the DOM. That is what makes `raster-bench.js` time
  the real path under node.
- Load order lives once, in `index.html`; `experiments/lib.js` parses the `<script src>`
  tags and requires exactly that order, so node and the browser cannot drift.
- The camera moves only through `GEO` (`lookAt`/`panBy`/`zoomAt`/`setPreset`), which marks
  the view dirty; `GEO.rebuild` clears it. Assigning `P.view` directly cannot happen.
- One file per entity or concern; each sim kernel is a function `(state, dt)` reading the
  previous buffers and writing its own output. Mark + gather for all cross-entity transfer.
- All state in typed arrays with fixed capacity (`js/state.js` owns allocation);
  `js/params.js` owns the defaults of design §9. Float64Array for geometry and fields,
  integer arrays for ids and enums.
- Hot path rules from `AGENTS.md`: preallocated scratch, reused LUTs rebuilt only on view
  change, no closures/strings inside a frame, HUD text at 2 Hz.
- Validation harness = `experiments/*.js` node scripts printing PASS/FAIL and the measured
  numbers (this repo has no test runner). `experiments/smoke.js` loads the page scripts in
  page order under a minimal DOM shim and runs frames in node — every phase's wiring must
  pass it. A phase is done when its scripts pass and the result is recorded in the worklog.
- Worklog: `archive/0.1.0-worklog.md` starts at M0 and gets one entry per completed phase
  (steps, validation, numbers), always ending with a next-step suggestion. The finished plan
  moves to `archive/` at M6.3 (per the `AGENTS.md` workflow).
- Scales, maps and any number quoted from the design are reproducible with
  `node experiments/scale-check.js`; extend that script rather than re-deriving numbers.

## 2. Phases

### M0 — Scaffolding and scales (1–2 d)

M0.1 `params.js`, `rng.js`, `geom.js`: row schedule (`y_i`, `h_i` closed forms), fan
    topology tables (`band`, `pitch`, neighbour lists across coarse-fine faces), display
    maps `u(y)`, `y(u)` and the two LUT builders.
M0.2 `state.js`: the full fixed-capacity layout of design §2 (columns, stacks, plates,
    ribbons, plumes, vents, toy boxes, deposits, fan T, ledger) + reset — the design pins
    every field, so the M0 layout is the final layout, no rework in later phases.
    `sim.js` loop with both clocks (K0 clocks/Tm/events inline, K1–K9 slots empty),
    `perf.js`, `ui.js`: two sliders (log feel), pan/zoom (per-axis presets: default,
    overview, crust, basin), HUD.
M0.3 `render.js` debug view (toggleable): fan cells, row edges, real column ticks, plate
    boundary lines, the asinh grid lines, scale readout (km/px, m/px under cursor) — the
    section is a visible measuring tool from day one.
M0.4 `experiments/lib.js` + the view/scale/smoke harnesses; outputs saved to
    `experiments/logs/`.

Done: `node experiments/scale-check.js` and `view-check.js` print ALL PASS — `q` closed form
vs Σh = R, sky rows = 34, fan = 7155 with a 1-cell bottom band, the neighbour stencil
symmetric in face *and* distance with face conservation, `|y(u(y))−y| < 1e-12`, the column
LUT equal to a brute-force owner over wrap-crossing / x40 / non-uniform / 1-column /
0-column windows; the page draws the mesh; both sliders move their clocks.

### M1 — Stacks and the section look (2–3 d)

M1.1 `columns.js` layer stacks (push/merge-on-full/sums, removeTop, layerAt) over the M0
    buffers; `surface.js` static isostasy (elevation + wrapped slope) — moved forward from
    M2.3 because the initial relief *is* isostatic and the sediments need the basin shape.
    Initial planet: fbm land mask on a circle (seamless at the wrap) → quantile continental
    fraction → felsic thickness, oceanic `hMaf = hMafNew(Tm)`, seeded sediments in basins,
    age ramps from the initial ridges, half-space-cooling fan-T lid; profile → fill →
    profile.
M1.2 `render.js` headless body pass: per-screen-column profile (interpolated tops + relief
    noise scaled by local relief), then three pointer walks — air/water, the stack painter
    with bedding stripes down to the Moho, the fan below via the per-row LUT; prebuilt
    lith/mantle/water/air palette tables so the pass is multiply-add; overlay draws the
    profile and Moho lines. `ui.js` geology probe (column, layers, flags, age, mantle dT).

Done: a believable geological section at the four presets (bedding visible at x10/x40); the
50 m bed is a thin dark line at x10 (design §1.4) and stays exactly 50 m for 1e5 frames;
`experiments/raster-bench.js` ALL PASS with the body raster <= 6 ms at all four presets;
the probe reads lith/age/thickness/flags of any picked bed; `smoke.js` and `view-check.js`
stay green.

Done: a believable geological section at the three presets; a 50 m bed is a thin dark
line at x10 zoom (design §1.4 table); probe reads lith/age/thickness of any picked bed;
`experiments/raster-bench.js` within budget (≤ 6 ms).

### M2 — Tectonics (3–4 d)

M2.1 `mantle.js` streamfunction + `ext` + `Tm(t)`; `plates.js` solve and boundaries
    (hysteresis, polarity, trenchDist).
M2.2 `columns.js` move + wrap sort; `crust.js` K4: gap spawn (rift shares vs oceanic),
    overlap consume (subduction, collision, accretionary prism), transforms; suture and
    split events at ~1 Myr cadence.
M2.3 `surface.js` isostasy + thermal subsidence + `zDyn` (trench) + flexure; age/damage
    updates in `crust.js`.

Done: two plates drift with correct relative signs; a ridge spawns symmetric columns
(±20% counts over 20 Myr at dt 50 kyr); a trench consumes at rate = relN × length ±10%
and piles a prism; a collision thickens `hFel` and builds a foreland bulge via flexure;
`experiments/ledger-check.js` (felsic/mafic/sed mass) PASS; dt slider 10–100 kyr gives
the same history topology (dt-insensitivity smoke).

### M3 — Sediments (2 d)

M3.1 `surface.js` erosion (knee law), one-hop routing gather, deposition layers with
    `wet/unconformity` flags, turbidite half-pass; placer load riding the sediment.
M3.2 Ledger extension: erosion↔deposition exact; `unconformity` flag when a layer top
    is beveled before burial.

Done: a cone sheds to its adjacent basin and the fill burs in visible beds (tabular,
onlapping the flank at the column scale); total crust+mobile mass constant to 1e-6
through a 50 Myr run; placer shows downslope of its source in the probe.

### M4 — Slabs, plumes, melts (3 d)

M4.1 `slab.js` ribbons: consumed stacks append, polyline descent with dip steepening,
    respacing; cold anomaly fed into fan T.
M4.2 `mantle.js` plumes (heads + conduit markers, LIP growth on arrival);
    `magma.js` wedge melt from ribbon water × fan T, chamber fill, sill/underplate spill.
M4.3 `crust.js` arc enrichment from ribbon recycling (`kRec`), collapse diffusion
    active above `hCollapse`.

Done: a subducting slab is a visible descending stratified tongue with a cold halo; arc
vent supply correlates with convergence rate (measure in `experiments/ledger-check.js`
water/melt ledger); a plume arrives, swells, and leaves an LIP stack on the column;
after ~4 Gyr `|u|` decays below 1 mm/yr (stagnant lid).

### M5 — Toy eruptives and the second clock (3–4 d)

M5.1 `erupt.js` toy box: pile CA (repose slough), freeze, crater/dome styles;
    particles (ballistic pyroclastics, buoyant ash); `magma.js` eruption schedules on
    the eruptive clock (effusive vs explosive from gas + pressure).
M5.2 Write-back: mass → stack layers (`tephra`, `lava`), pile → edifice record;
    `render.js` cone fill clipped at the profile + eruption FX overlay.

Done: at default zoom a stratocone grows to ~17 px wide and ~16 px tall and erupts with
a plume and pyroclastics at the 30 min/frame default (minutes-scale at the slider max);
tephra and lava layers appear in the probe with correct mass (ledger); empty chamber
idles the toy under fast geology, over-full chamber builds sills instead (ledger);
`experiments/erupt-bench.js` ≥ 60 toy steps/s at 16 vents.

### M6 — Deposits, save/load, polish (2–3 d)

M6.1 `ore.js` depth-resolved deposits (design §4.7) + extraction overlay and ranked list;
    deposit symbols in `render.js`.
M6.2 `state.js` JSON save/load round trip (bit-identical resume), `ui.js` buttons and
    seed entry; `sim.js` diag HUD (invariants every 2 Hz).
M6.3 Acceptance pass (below), `archive/0.1.0-worklog.md`, tune defaults from
    `experiments/` numbers.

Done: full acceptance below; save → reload → 1000 frames reproduces the live run
bitwise; the plan's numbers still match `scale-check.js`.

## 3. Acceptance (whole project)

1. Scales and geometry: `node experiments/scale-check.js` and `node experiments/view-check.js`
   print ALL PASS and match the design §1 tables (fan 7155, w0 78.18 km, the isostasy
   calibration points, the stencil symmetry).
2. Rigid transport: 3 columns of one plate migrate 2000 km at 5 cm/yr with exact spacing
   (wrap crossing included); no drift over 10^5 frames at dt 50 kyr.
3. Crust cycle: prescribed convergence reproduces the consumed length (±10%) and the
   prism/arc mass ledger; prescribed divergence spawns rift-share margins thinning
   35 → 15 km over ~3 columns before oceanic crust starts.
4. Sediments: cone-to-basin ledger exact (1e-6); beds accumulate visibly; an
   unconformity cuts older beds in the probe.
5. Slab-to-arc: water released at 50–200 km equals melt delivered ±20%; the arc sits
   1–3 columns behind the trench on the overriding side.
6. Eruptions: one effusive and one explosive run each build a 10–30 px edifice at the
   default window with conserved mass; write-back layers read back through the probe.
7. Deposits: > 60% of `oArc` deposit mass sits under edifice/arc columns; placer downslope
   of orogenic/arc sources; VMS on buried seafloor horizons.
8. Stability: 500 Myr at dt 10 kyr and 100 kyr with finite state, ledger drift < 0.1%
   (excluding recorded sources), < 5% boundary flicker per frame.
9. Performance: body raster ≤ 6 ms (min-of-runs, so a throttled shared CPU cannot fail a
   fast implementation) and full frame ≤ 16 ms at 1280×560 on a desktop
   (`experiments/raster-bench.js`); HUD rebuild at 2 Hz only.
10. Determinism: same seed + sliders ⇒ bitwise-identical 1000-frame `state.hash()`
    (`experiments/smoke.js` runs it twice and compares).
