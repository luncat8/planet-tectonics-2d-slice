# 0.1.0 — Design: 2D slice simulation and rendering engine

Normative specification of the vertical cross-section planet: scales, state, physics and
rendering. Written to be implemented without any other document. Development plan:
`0.1.0-plan.md`. Scale numbers are reproducible with `node experiments/scale-check.js`.

## 0. Goal and requirements

From `draft.txt`, `AGENTS.md`:

- a 2D side-view slice of a planet with moving tectonic plates, sediments and deposits,
  mantle plumes, subduction, and visually good-looking volcanos;
- a smooth vertical log scale: fine at the surface (20 m class), coarse at the center
  (1000 km class), anchored at 0 m so the surface band is the detailed one;
- horizontal: ~512 cells at the surface, collapsing to a single cell at the center —
  cheap deep interior, detailed crust;
- eruptive mechanics at a toy scale so a volcano reads as a 10–30 px object in both
  width and height;
- double time scales: one slider for plate and plume time (10k–100k yr per frame), one
  for lava and eruptions (minutes–hours per frame);
- physics and deposit formation follow `https://github.com/luncat8/planet-geotectonics`
  (top surface view, `0.1.5-final-design.md`) adapted to the 2D slice;
- runtime per `AGENTS.md`: file:// friendly, classic scripts, no build, CPU JS.

Game realism, not research accuracy. Emergent-looking structure over solved flow.

## 1. Scale system

Four scales, deliberately distinct: the world, the sim rows, the display map, and the
toy eruptive cells. The draft's numbers pin all four; each mapping below is calibrated
so the numbers hold simultaneously.

### 1.1 World

Unrolled great-circle slice, periodic in x:

```
x : 0 .. 2*pi*R          R = 6371 km   (wrap length 40 015 km)
y : -R .. +33 km         altitude above sea level, sea level = 0 = radius R
```

Every point of the planet is on the slice; plates wrap forever with no walls. The disc
cutaway (radial re-projection of the same buffers) is an optional later view.

Rejected: a half slice (pole-to-pole arc) — it needs reflective end walls and invents
polar boundary processes that do not exist.

### 1.2 Sim rows (vertical discretization)

Geometric grading anchored at the 0 m band, equal ratio q between adjacent rows, the row
at 0 m is `h0 = 20 m`; the N ground rows sum to R. The draft's pair "20 m at surface to
1000 km at center" is exactly N = 64:

```
h_i = h0 * q^i        sum_{i<N} h_i = R        q = 1.18748        h_63 = 1006 km
```

The sky band mirrors the schedule upward to +33 km (34 rows). Sky rows carry **no fan cells
and no state** — air is not simulated; they exist so the profile, edifices and the ruler can
address the band above 0 m with the same graded metric. World y of any row edge is a closed
form `y_i = h0 (q^i - 1) / (q - 1)`.

| N | q | h at center row | crust rows | rows ≤ 100 m (cover) | fan cells |
|---|---|---|---|---|---|
| 48 | 1.26676 | 1342 km | 26 | 7 (317 m) | 5247 |
| **64** | **1.18748** | **1006 km** | **33** | **10 (488 m)** | **7155** |
| 80 | 1.14354 | 800 km | 41 | 12 (557 m) | 9063 |
| 96 | 1.11576 | 661 km | 48 | 15 (721 m) | 10903 |
| 128 | 1.08278 | 487 km | 62 | 21 (1042 m) | 14341 |

N = 64 is the default; `nRows` is a parameter in [48, 128]. The fine band is only the
top few hundred meters of rows — beds thinner than a row are **not** stored in rows.
Stratigraphy lives in column layer stacks (§2.2) which have unlimited sharpness; rows
carry only smooth fields (§2.4). That split is what makes 20 m sediments affordable.

Rejected: resolving every bed with rows (millions of rows at20 m to the center); a
two-slope piecewise grading (visible kink in any row-shaped rendering, no gain over
stacks).

### 1.3 Columns and the fan (horizontal)

- **512 Lagrangian crust columns** along x, nominal width `w0 = 2*pi*R/512 = 78.18 km`
  (derived from `wrap/nCols` in `params.js`, never hardcoded). They move, spawn and die
  (§4.2); capacity 768. 512 is the nominal count, like cell area in the reference design.
- **Fan grid** for the one Eulerian field (temperature): band 0 has 512 cells like the
  surface; the pitch doubles at 9 merge rows spread evenly over the schedule — row
  `round(k*(N-1)/9)`, k = 1..9 — so the last merge lands on the last row and the bottom row
  is **exactly one cell spanning the wrap**, matching §1.1's "single at the center"
  (N = 64 → 7155 cells, 4.6x cheaper than a uniform 32768). `round(k*N/9)` puts the ninth
  merge past the last row and leaves 2 cells at the center (7186) — measured and rejected.
  Adjacent bands meet at coarse-fine interfaces whose shared face is the *fine* cell's width
  on both sides; neighbours are a fixed 6-slot table per cell (left, right, down x2, up x2)
  carrying the face width and the centre-to-centre distance, so the stencil is face/dist and
  symmetric by construction (`experiments/view-check.js` asserts both symmetry and face
  conservation).

Rejected: 512 cells of constant pitch at every depth (sliver cells near the center, 4x
the cells); a general quadtree (unbounded neighbour lookup cost, no visual gain over the
structured fan).

### 1.4 Display map (vertical)

Screen y is a smooth signed-log of altitude — `asinh` with a linear core at 0 m:

```
u(y) = asinh(y / yLin)        yLin = 40 km
screenY = (uTop - u(y)) / duPx   duPx = (uTop - uBottom) / canvasHeight
```

`y` and `u` increase upward; canvas pixel y increases downward. For a camera window
`[uBottom, uTop]`, `uTop` maps to screen row 0 and `uBottom` to `canvasHeight`; the inverse
is `y(screenY) = yLin · sinh(uTop − screenY · duPx)`. Raster LUTs, profile/mesh overlays,
horizontal grid lines and labels all use this same transform.

Within ±40 km of sea level the map is linear (crust, relief and edifices draw to true
proportion); beyond it compresses logarithmically (the 6371 km of mantle is 159:1
compressed at the overview). Smooth at 0, no kink.

Calibration at the default window — 3000 km wide, y in [+33, −300] km, 1280×560 —
(`experiments/scale-check.js`):

| quantity | value |
|---|---|
| horizontal scale | 2.34 km/px (38 columns visible, 33.4 px each) |
| vertical scale at y = 0 | 247 m/px |
| vertical scale at y = −70 km | 499 m/px |
| vertical scale at y = −200 km | 1.26 km/px |
| cone 20 km x 2 km | 8.5 x 8.1 px |
| cone 40 km x 4 km | 17.1 x 16.1 px ← the 10–30 px band |
| cone 60 km x 8 km | 25.6 x 31.9 px |
| 50 m bed at −5 km | 0.20 px at zoom x1, 2.0 px at x10 |
| overview (full depth) | 465 m/px at 0, 74 km/px at center, cone 17.1 x 8.5 px |

A realistic cone is square on screen at every band zoom because the map's vertical
exaggeration at the surface band is ≈ 9.5x horizontal — the draft's "toy looking 10–30 px
volcano" falls out of the map itself, with no drawn distortion.

Zoom is free (any magnification of the map); useful range x0.3 – x200. The view keeps two
factors, `zoomX` (linear in x, shares the pan) and `zoomY` (linear in u). The wheel scales
both together — uniform zoom is what keeps a cone square at every magnification — while the
presets set them. Base scales come from the calibration window alone (`winW/canvasW`,
`uSpan/canvasH`), so a canvas of another size shows more world at zoom 1, never a different
scale. The Crust and Basin presets are *uniform* zooms (divisor on both axes) about a chosen
depth, so the §1.4 bed-pixel table holds in the preset itself; the Overview is the one
anisotropic preset, keeping the default 2.34 km/px horizontal while fitting the full depth —
the anisotropy that keeps its cone 17.1 px wide in the table above.

| preset | zoomX | zoomY | u centre |
|---|---|---|---|
| Default | 1 | 1 | centre of [+33, −300] km |
| Overview | 1 (full 3000 km strip) | 0.53 (full depth) | centre of [+33, −6371] km |
| Crust | 10 | 10 | u(−10 km) |
| Basin | 40 | 40 | u(−3 km) |

Rejected (same window, same 40 x 4 km cone, measured):

- row-uniform rendering of the graded rows (the "log display as rows" idea): 17.1 x
  71.3 px — a 4.2:1 needle; the graded rows over-weight the top band when distributed
  evenly over pixels. Rows are a sim mesh, not a display transform.
- linear vertical: 17.1 x 6.7 px pancake; a 10 m bed is 0.017 px even at x10 zoom.
- signed log with kink at 0 (`sign(y)·log(1+|y|/20)`): 17.1 x 35.9 px needle plus a
  visible slope break at sea level.

### 1.5 Toy eruptive cells

The eruptive sim works in **screen-anchored square cells**: 1 toy cell = 1 px at the
default zoom (world footprint at the surface band ≈ 2.34 km x 0.25 km via the display
jacobian — anisotropic, accepted: toy mechanics are caricature, only mass is conserved).
A vent domain is 48 x 32 toy cells; a grown edifice is 10–30 cells wide and tall — the
draft's "10–30 px volcano" is literally 10–30 toy cells. At most 16 vent domains alive.

Toy dynamics run in screen space (square pixels, isotropic rules); write-back converts
toy cell volumes to world mass with the jacobian (§5.3).

Rejected: square world cells (a square world cell is 9:2 on the default pixel — piles
render as bricks; "10–30 px" is a screen statement); one global toy grid over the whole
surface (volcanos are local, 512-wide toy rows waste 95% of the cells).

### 1.6 Time model — two clocks

Two independent sliders, both accumulate per frame (rates scale with dt, thresholds are
event-like, so slow-mo is smooth down to dt → 0):

| clock | slider | range | default | drives |
|---|---|---|---|---|
| tectonic `dtGeo` | Plates & plumes | 0 – 200 kyr/frame (log feel, sweet 10–100 kyr) | 50 kyr | columns, plates, mantle flow, plumes, slabs, erosion, cooling |
| eruptive `dtErupt` | Lava & eruptions | 0 – 4 h/frame (log feel, sweet minutes–hours) | 30 min | toy cells, particles, ash, chamber drain |

They are decoupled on purpose: geological years and lava hours differ by ~10^9; one knob
cannot serve both. Coupling is only through the magma buffer (§5.2): geology fills a
chamber at a rate in km3/Myr, the toy drains it in km3/h. Cranking tectonics does not
speed up lava; it fills the chamber faster (over-full spills into sills and underplating).
Eruptive time is free when the chamber is empty and capped by supply.

## 2. State

All state in typed arrays with fixed capacity, allocated once (`js/state.js`). Sharp
material is Lagrangian (columns, ribbons, plumes, toy cells); the only Eulerian grid
field is temperature on the fan.

### 2.1 Plates (≤ 32)

1D intervals on the wrapped line: `id, x0` (anchor of the interval's left end), column
count, `u, uPrev` (cm/yr), `damage` aggregate. A plate is rigid in 1D: pure translation.
Plates wrap; a plate containing x = 0 is stored as a rotated interval (anchor at its own
member column).

### 2.2 Columns (Lagrangian crust, cap 768)

| field | unit | meaning |
|---|---|---|
| `x` | m | position on the line, moves with its plate |
| `plate` | id | owner |
| `age` | Myr | lithosphere thermal age (0 at a ridge) |
| `hFel hMaf hSed` | m | cached layer sums (felsic 2750, mafic 2950, sed 2400) |
| `damage` | 0..1 | accumulated weakening |
| `zDyn` | m | transient dynamic topography, relaxes to 0 |
| `fert` | 0.5..2 | ore fertility, fixed at birth |
| `oVms oMaf oArc oOro oBas oPla` | 0..1 | ore potentials (§4.7) |
| `volc` | slot | volcano record index or −1 |
| `edge, edgeAge` | type, Myr | boundary state with the right neighbour: classified type (hysteresis) + time in that state (suture timer, §4.3) |
| `trenchDist` | 0..3 columns | distance behind a subduction edge on the overriding plate; 0 elsewhere (§4.2) |

**Layer stack** (per column, capacity 96 layers in the fixed slot range
`col*layerCap + k` — O(1) indexing, no compaction events, ~1 MB for the whole table; a
full stack merges its thinnest same-lith adjacent pair, and an all-alternating stack that
has no such pair may merge across classes. Record that class transfer by source/destination
lithology in `ledMixOut`/`ledMixIn` (and increment the `ledMix` event count) so per-class
mass remains auditable): each layer is
`(thick, lith, age, flags)` bottom-up; `lith ∈ {sed, fel, maf, tephra, lava, sill}`,
`flags` bitset: `wet`, `ore-host`, `unconformity`. Layer sums give `hFel/hMaf/hSed`;
a deposit (§4.7) is a record `(column, layerIndex, class, grade)` in a global deposit
table — depth-true, visible in section.

This is the reference design's rule in stronger form: crust never lives in grid cells,
so 20 m beds stay exactly 20 m for 10^5 frames. The stack is also the save file's bulk.

### 2.3 Ribbons, plumes, vents

- **Slab ribbons** (≤ 8): when oceanic columns are consumed (§4.3) their stacks append to a
  trench-anchored polyline whose nodes carry `(x, y, dip, T, water)` while the ribbon as a
  whole carries **one** layer stack — a per-node stack would multiply the layer table by the
  node count for no visible gain. The ribbon
  descends into the mantle (§4.5), carries the subducted stratigraphy (and its ores)
  with it, and dissolves at 660 km.
- **Plumes** (≤ 6): `(x, y, r, strength, conduit[] )` rising from −2000 km class depths;
  conduit is a marker chain carrying a hot anomaly (§4.4).
- **Vents** (≤ 16): `(x, w, h, style, chamber{V, gas}, toy box slot)`. Styles: strato,
  shield, fissure, arc. The vent is sub-column (a volcano is half a column wide) and is
  drawn from its record, not from column resolution (§5.3).

### 2.4 Fan field (Eulerian, smooth only)

`T[cell]` — mantle/lithosphere temperature anomaly around a depth-adiabat reference,
plus frame scratch for the diffusion stencils and coarse-fine exchange. Advected
semi-Lagrangian (T is smooth, smearing is fine — the only advection on a grid in the
whole engine). Sources: ribbon cold anomaly, plume heat, radiogenic relaxation.

### 2.5 Mass ledger

`ledProd`, `ledCons`, `ledMixIn` and `ledMixOut` are `Float64Array(LITH.n)` volumes in m³
per unit depth into the page; `ledMix` counts cross-lithology stack merges. A transfer
between columns does not touch the ledger. `massBy` is scratch for measured column mass;
the invariant is stated in §6. Before a kernel turns a cross-section stack into a sink or
source, it records that flow by lithology.

## 3. Frame pipeline

One frame = one tick of both clocks. Kernels read the previous state and write their own
outputs; cross-entity transfer is mark + gather (deterministic, no atomics).

| # | step | over | reads → writes |
|---|---|---|---|
| K0 | clocks, `Tm(t)`, queue due split/suture/compact events (~1 Myr cadence) | — | clocks, pending event count |
| K1 | mantle: ψ-flow at needed points, plume rise, ribbon descent/dehydration/melt, fan T step | plumes, ribbons, fan | T, supplies |
| K2 | plate solve: per-plate mean fit `u = mean(uMantle + w)` over its columns, relax, vMax | plates | u |
| K3 | move columns with their plate (wrap-aware record sort), boundary classify with hysteresis, trenchDist | columns | x, edge types |
| K4 | contact: gaps → spawn (rift share or oceanic), overlaps → consume (subduct/collide/accrete) | columns | stacks, ribbons, deposits |
| K5 | apply queued topology events; column age, damage/heal, zDyn relax + flexure, collapse diffusion, arc/plume growth, ore accumulate, chamber fill | columns | as listed |
| K6 | surface: isostasy profile, erosion, one-hop routing, deposition layers | columns | stacks, profile |
| K7 | vents: chamber pressure events (eruptive clock), toy step, particles | vents, toy | edifices, stacks |
| K8 | render (§7) | — | canvas |
| K9 | diag: invariants, counters | — | HUD |

K0 advances the cadence accumulator and records how many topology events are due; it does not
mutate columns or plates. K5 applies those events after K4 contact resolution and before K6
rebuilds the surface profile, so every frame ends with one consistent column topology.

## 4. Simulation engine

Physics follows planet-geotectonics `0.1.5-final-design.md`; the adaptations to a 1D
plate line and a 2D section are stated below. Same constants where not overridden (§9).

### 4.1 Mantle driver

Use a periodic 2D streamfunction (exactly incompressible by construction). For modes
`k = 2..5`, quantize the nominal wavelength `Lm` to an integer harmonic of the wrapped
world:

```
n_k = round(k * wrap / (2π * Lm))       κ_k = 2π * n_k / wrap
θ_k = κ_k * (x + c_k*y) + ω_k*t + p_k
ψ(x,y,t) = Σ_k [U0 / (4 * κ_k * c_k)] * sin(θ_k)
(u_x, u_y) = Tm(t)^2.5 * (∂ψ/∂y, -∂ψ/∂x)
```

At the surface, `uMantle(x,t) = u_x(x,0,t) = (U0/4) * Tm(t)^2.5 * Σ cos(κ_k*x +
ω_k*t + p_k)`. Integer `n_k` makes `ψ`, velocity and extension exactly periodic across
`x = 0 / wrap`; `Lm` remains the nominal wavelength scale. Modes are seeded once from the
run seed: `c_k ∈ [0.2, 0.4]` (obliquity), a precession period `T_k ∈ [200, 500] Myr`
with `ω_k = 2π/T_k`, and `p_k ∈ [0, 2π]`.

Plumes are deferred to M4: 3–6 Gaussian upwellings, radius ~300 km, life 50–150 Myr, rise
speed ~5 cm/yr * Tm, heat and radial outflow near the head. The base mantle extension field
is sampled at the columns as the periodic derivative of `(uMantle − uPlate)`; `ext` has
units 1/Myr and `extRef` normalizes it when damage is updated. M4 adds the plume contribution.

This replaces the reference's spherical harmonics (its §6.1): a streamfunction cannot
diverge, which the 3D harmonic field only approximates.

### 4.2 Kinematics and the plate solve

Columns move by translation `x += u_plate * dtGeo` (exact; wrap is modular). Per frame
the plate's velocity is the least-squares fit to the flow over its extent — in 1D
translation the reference's 3x3 solve (its §6.2) degenerates to a mean:

```
uTarget = (1/L) * integral_plate ( uMantle(x, 0) + w(x) ) dx
u      += (uTarget - u) * min(1, dtGeo / 0.5 Myr)        |u| <= vMax
```

Equivalent basal velocities `w` (its §6.3, per column): slab pull `+vSlab·s(age)` on the
subducting column of a subduction boundary (s = min(1, age/70 Myr)); ridge push
`-kRidge * slope` on oceanic columns; collision resistance `-vColl·f(hFel)·(-relN)/vRef`
on both sides of C–C convergence (explicit, previous frame's relN). `cD(Tm) = exp(Ea(1/Tm−1))`
scales the non-drag terms. Cooling stiffens the asthenosphere; `|u| → 0` is a stagnant
lid with no switch.

Boundary classification between adjacent columns of different plates: `relN = u_j − u_i`
with hysteresis (±2/±1 mm/yr as its §3.3); polarity (its §3.3): oceanic = `hFel < 8 km`;
O–O older subducts, O–C oceanic subducts, C–C collides. `trenchDist` = 1..3 columns
behind the trench on the overriding side = the arc factory.

### 4.3 Crust cycle (its §4, in 1D)

- **Gaps** (divergence): for adjacent sorted column centres with separation `d`, the
  midpoint is unowned when `d/2 > rGap·w0` (equivalently `d > 2·rGap·w0`); the initial
  pitch `w0` therefore creates no gap. At an opening boundary, spawn at the midpoint and
  assign the new column to the left-hand plate in sorted x order (the last-to-first seam
  uses the left plate at the wrap). Donors = nearest K = 3 columns on each side. If both
  donor sets are continental (`mean hFel ≥ hRiftBreakup`), the rift column takes `1/(K+1)`
  of each donor's `hFel`, `hSed` and ore mass (donors thin) and starts hot
  (`age = 0`, `damage = 0.6`). Otherwise spawn
  oceanic crust (`hMaf = hMafNew(Tm)`, `oVms` seeded) and record the mantle source in the
  mass ledger. Result without extra state: rift valley → thinning margins → ocean.
- **Overlaps** (convergence): a different-plate pair within `rContact·w0` and closing
  faster than `ε_hi` resolves by polarity (its §4.3 table). Subduction removes the oceanic
  loser; half of its sediment is transferred to an accretionary-prism layer on the
  overriding margin, and its remaining stack enters a trench ribbon for later descent
  (M4). C–C collision removes the thinner-felsic column and transfers its complete stack
  to the winner; collision does not create a subduction prism. Every transfer is recorded
  by lithology; nothing silently vanishes.
- **Transforms**: this 1D kinematic slice has no independent out-of-plane plate velocity,
  so M2 treats non-opening, non-closing contacts as neutral and mass-preserving. Defer
  `relT`-based transform damage until a transverse degree of freedom is explicitly added.
- **Suture**: a C–C contact whose |relative speed| stays < vSuture for > 20 Myr merges the
  smaller plate into the larger (columns re-tagged). K0 queues split/suture work at the
  ~1 Myr cadence; K5 applies it after K4. Splitting follows the reference's damage-corridor
  rule (its §5): a corridor that separates two bodies of ≥ `minPlateCells` (24 at 512
  columns) becomes two plates and its damage drops to 0.5.

### 4.4 Column update (its §6.5, §7.2, K5)

Age grows; `damage` accumulates from `ext` divided by lithosphere strength
(`strength` from `hFel`, `age`, `Tm`) and heals slowly. The `kDamT·|relT|` term is deferred:
this 1D plate state has no independent transverse velocity. `zDyn` relaxes
(τ_dyn 10 Myr) and is fed by trench (`-zTrench`) and plume swell (+1 km); flexure is a
1D Laplacian on `zDyn` along the profile (kFlex) — forelands appear beside orogens;
felsic collapse diffuses `hFel` between columns above `hCollapse` (mass conserving,
symmetric) — plateaus spread and cap mountain height. Arc columns grow
(`hFel += kArc·Tm·|relN|dt/vRef`) at trenchDist 1..3 while subduction runs; plume-head
columns grow `hMaf` (LIP) and set `oMaf`. Chambers fill from melt supplies (§4.5).

### 4.5 Ribbons, dehydration, melts

Ribbon descent: each polyline node moves along its dip (45–60°, steepening with depth)
at the sink rate `vSlab·s(T)` plus the local ψ-flow sampled at (x, y); nodes are
respaced as the polyline stretches. Water budget rides the layers: at 50–200 km depth a
fraction `kDehy` per Myr releases into the overlying wedge. Wedge melt (arc magma):

```
supplyArc(x) = kMelt * sum_nodes [ water(node) * max(0, T(x, y) - Tc) ]
             over nodes at 60-150 km depth within 50-300 km laterally
```

Plume-head melt feeds its column's chamber likewise. Ribbon layers (and their ore
records) persist to 660 km where the ribbon dissolves into the T field. This is the
2D-slice payoff the surface view could not show: the slab, its sediment veneer, the
wedge, and the plumbing line up in one section.

### 4.6 Surface: isostasy, erosion, sediment (its §7, in 1D)

Ported formulas (its §7.1–7.3), neighbors = the two adjacent columns:

- elevation `z = zRef + buoy − therm + zDyn` from the layer sums (same constants and
  calibration points); `wet = z < 0`; the **static** half (elevation + profile) is needed by
  M1 — the initial planet's relief *is* isostatic and the renderer paints against it — while
  the **dynamic** half (erosion, routing, deposition) lands in M3;
- erosion `e = kEro·max(0,z)·(z/zKnee)²·(1+2·slope/slopeRef)·dtGeo`, removed top-down
  through the stack (sed, then fel, then maf); mobile load `m, mFel, m` placer `p`;
- one-hop routing to the lower neighbor each frame (gather form); underwater halves the
  throughput (turbidite pass-through); what stays deposits as a **new layer** with its
  `wet/unconformity` flags — the section's visible bedding accumulates by itself.

### 4.7 Metallogeny — depth-resolved deposits

The six saturating potentials of its §8 (`fert`-scaled, `(1−o)` saturation, 500 Myr decay)
accumulate on columns at the same factories: VMS at oceanic birth, mafic at plume/rift,
arc at trenchDist 1..3 (recycling enrichment from the ribbon), orogenic near C–C/transform
on thick `hFel`, basin in wet deposited sediments, placer riding the eroded load.
The slice adds **emplacement depth**: each extraction writes a deposit record at the
hosting `(column, layer)` — placer on an unconformity top, VMS on a buried seafloor
horizon, porphyry as a sill-like body 3–8 km under a vent, orogenic veins in the
collided root. Extraction (on demand): local maxima of a 1-cell blur, ranked, with a
context tag — but placed in section, visible in the render, not surface points.

### 4.8 Cooling

`Tm(t) = Tfloor + (Tm0 − Tfloor)·exp(−t/τ_cool)` (its §6.4): scales mantle speed,
`hMafNew`, arc production, plume strength, damage strength. Tectonics ages from a hot
start of many fast plates to a stagnant lid over ~4 Gyr of geologic time.

## 5. Toy eruptive model

Runs only while a vent is active (erupting or intruding); its output becomes geology and
the coarse sim owns it afterwards. Tick = `dtErupt`.

### 5.1 Toy domain

Per active vent: a 48×32 toy-cell box on the profile (edifice + shallow conduit + air
above). Cell state: height-map pile `(h, lith ∈ {tephra, lava}, T)` per toy column
plus a particle pool (≤ 512) for pyroclastics and ash. Rules (totalistic, 2 passes):

- vent feeds: blobs of lava or, if gas fraction > 0.4, pyroclastic particles + an ash
  column (particles ballistics + slow buoyant drift, settle as tephra);
- pile cells at slope > repose slough to the lower neighbour (2 passes ≈ angle of repose);
- T relaxes to air; T < Tsol freezes the cell into edifice lith (lava ⇒ massive, tephra
  ⇒ layered look);
- crater collapse when the plug is thick and gas is low (dome-building vs explosive is
  the `style` + gas curve).

### 5.2 Chambers and schedules

Chambers fill at `supply(x)` (§4.5) in world volume per Myr of geologic time; V converts
to toy volume per the jacobian. `dtErupt` drains: effusive rate ∝ (1 − gas)·sqrt(P − P0),
explosive when `gas > 0.4` and `P > 1.3 P0`, cadence minutes–hours. Empty chamber = the
toy idles no matter how fast geology runs; a full chamber spills into sills (a `sill`
layer in the stack) and underplating (`hMaf`) — no state leaks.

Vent lifecycle: a column gets a vent slot when its chamber first reaches `Vbirth` (or
reuses the slot of a dead vent); a vent dies when V stays below `Vdie` for `tauVent` —
the pile is already written back to the stack each K7, so a dead vent leaks no state.
Style is fixed at birth: arc at the arc factory, plume-head or rift → shield, else
strato; the vent's `(w, h)` is the edifice record (§5.3).

### 5.3 Write-back and the edifice record

Every K7, the toy box integrates to world: frozen mass → layers of `tephra`/`lava` in the
owning column's stack (with `fert`-carrying volcanic ash as a basin-ore input), the pile
profile sampled to the **edifice record** `(x, w, h, style)` — a sub-column parabola the
renderer draws clipped against the profile. Burial deeper than its flank lowers `h`
gradually (buried seamounts flatten); erosion of the column also cuts `h` before it cuts
the flanks. Mass is exact: Σ toy cell volume × jacobian = Σ stack additions.

## 6. Determinism, invariants, save, performance

- RNG: one seeded xorshift128 (`js/rng.js`), fixed iteration orders; a run is
  bit-reproducible from `(seed, sliders, params)`.
- Invariants (K9, asserted by `experiments/ledger-check.js`): for each lithology,
  active mass (columns, ribbons, mobile load and toy) + cumulative sinks + `ledMixOut`
  equals initial mass + cumulative sources + `ledMixIn` within 1e-6 relative. Cross-class
  compaction transfers cancel in the total. Ore mass per class is bounded; no NaN; column
  count is within capacity; every layer stack is in [0, 96] layers.
- Save/load: one JSON blob = columns (stacks included), plates, ribbons, plumes, vents,
  deposits, fan T, globals; `params` recorded in the header. Fan T is saved (it holds
  slab/plume history) but its absence may be approximated by a rebuild.
- Performance budget at 1280×560 on a desktop: body raster ≤ 6 ms, sim K0–K7 ≤ 4 ms,
  toy ≤ 1 ms per active vent, HUD text rebuilt at 2 Hz (never per-frame strings). No
  allocation in the frame loop.

## 7. Rendering engine

Hybrid: a per-pixel body raster (ImageData) + canvas 2D overlay. Per-pixel is what makes
thin beds crisp at any zoom without quad seams.

- **LUTs** (preallocated): per screen row → `(worldY, row, rowBase, rowCnt, 1/pitch)`,
  rebuilt on view change only; per screen column → `(colIndex, xFrac)`, rebuilt every frame
  by one pointer walk over the x-sorted columns (columns move, the view LUTs do not). The
  row LUT turns the fan cell lookup into one multiply — no search per pixel.
- **Headless core**: `render.body(st, px, w, h)` writes into a caller-supplied buffer and
  never touches a canvas it fetched itself; only `render.present()` and `ui.js` touch the
  DOM. That is what lets `experiments/raster-bench.js` time the real raster under node.
- **Body pass**, per pixel column top-down (pointer walk over the column's stack —
  O(pixels + layers)):
  1. profile height `yProf(x)` — smooth spline through column tops + slope-scaled relief
     noise + edifice parabolas (precomputed per screen column);
  2. `y > yProf`: air gradient, or water fill where `z < 0` (flat sea at 0), or ash;
  3. `y < yProf`: the stack layer at that depth (lith color table, ±20% value striping
     by layer index for bedding, `wet` blue cast, sill/dike magmatic tint); deposit
     records overprint as small lenses/vein splashes;
  4. below the stack (deeper than the Moho): fan T field bilinear sample, banded mantle
     color + thermal glow; slab ribbons and plume conduits are sampled as signed-distance
     fills of their polylines (cold blue, hot amber) over the mantle;
  5. ore-host shading and last: viewport-level vertical grid ticks every 10 km (asinh
     spacing) so the exaggeration is honest to read.
- **Overlay pass** (canvas 2D): profile line, plate boundary ticks with type glyphs
  (ridge / trench + teeth direction / transform arrows), vent glyphs sized `w`, eruption
  particles and lava glow (toy space → screen), deposit symbols, probe crosshair + panel,
  HUD (two clocks, Tm, fps/step), slider widgets.
- **Views**: default window (§1.4) and presets: Overview (default width × full depth,
  §1.4 zoom note), Crust (×10), Basin (×40). Disc re-projection is a later optional pass over the same
  buffers (radial: `screenY ↔ radius`, `screenX ↔ angle`).

The renderer never allocates per frame and never reads state it does not draw (no
readback, no measureText in the loop).
